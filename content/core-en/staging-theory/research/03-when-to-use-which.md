# TH-R3 — When to Use Which: the decision layer of the Theory reference

Research briefing for BandReady's **Theory** section (the reference-grammar "map", as distinct from
the practice module's "walking route").
Compiled 2026-07-31. Consumers: the theory design agent (chapter schema + ordering), the chapter
authors, the contrast-board authors in the practice module who need a canonical statement of each
decision, and whoever writes the learner-facing chapter intros.

**What this file is.** The user asked, repeatedly, for *"when to use where kind of stuff"*. This is
that file. It is a catalogue of every genuine **choice point** in English grammar — every place where
two or more forms are both perfectly grammatical and the learner has to pick — written as a
**decision guide**: the question to ask yourself, the answer for each option, a minimal pair where
the same sentence changes meaning when the form changes, and the deciding factor in one line.

**Why it is the most valuable part of the reference.** Learners can usually *build* a form. Corpus
evidence and our own error ranking both say the expensive errors are **selection** errors, not
formation errors — see `content/core-en/staging-grammar/research/02-what-moves-a-band.md` §4 items 1,
3, 8, 10, 14 and §9 item 3, which names "when to use which" as its own first-class item type. A
learner who knows how to form the present perfect and does not know when to use it will still write
`I have visited Berlin in 2019`, and that sentence contradicts itself in a way an examiner cannot
step over.

`content/core-en/staging-grammar/research/01-syllabus.md` (what is taught, in what order),
`.../02-what-moves-a-band.md` (what pays — **read first; this file is kept consistent with it**,

## 0. How to use this file

### 0.1 The unit of this document is a DECISION, not a form

A theory chapter about the present perfect explains what the present perfect *is*: the paradigm, the
auxiliary, the past participle, the negative and question forms, the contracted forms. That belongs
in briefings TH-R1/TH-R2 and in the chapters themselves.

**This file starts where that ends.** Every entry below assumes both forms have already been taught
and answers only one question: *given that both are correct English, which one does this sentence
need?*

### 0.2 The fixed shape of a decision entry — authors must not vary it

Every decision below is written in the same six-part shape, and the theory chapters should render it
the same way every time, because the value of a reference book is that the reader learns where to
look:

| Part | What it is | Why it is there |
|---|---|---|
| **Ask yourself** | The single question, in plain words, that resolves the choice | A learner under time pressure can hold one question in their head, not a rule set |
| **The options table** | One row per form: *use it when* + an authored example | The comparison must be visible side by side, never on two separate pages |
| **Minimal pair** | The *same* sentence with only the disputed element changed, and what changed in the meaning | This is the only thing that proves a decision exists. Without it the learner thinks the two forms are synonyms and picks by habit |
| **Deciding factor** | One line, bolded, that a learner could write on their hand | The take-away. If a chapter has ten of these, the chapter has ten memorable lines |
| **Trap / false rule** | The plausible wrong reasoning that produces the error, named out loud | Teaching only the correct form leaves the broken form in place; the broken form came from a *reasonable* step that has to be interrupted (`02-what-moves-a-band.md` §3.2) |
| **Register** | SPOKEN / WRITTEN / BOTH, plus the IELTS-style task where the decision actually pays | A learner taught one undifferentiated "English" produces essay grammar in Speaking Part 1 and speech grammar in Task 2 (§25) |

Where a decision has more than two options (the future has five, articles have four), the options
table simply grows; the shape does not change.

### 0.3 Terminology, defined before it is used

The Theory section is for a learner with **zero grammar knowledge**. Every term below appears
somewhere in this file, so every term is defined here in plain words, and each chapter must define
again, locally, any term it uses. Repetition is correct in a reference book.

| Term | Plain-words definition | Example |
|---|---|---|
| **verb** | A word for doing or being | *run*, *is*, *decide* |
| **auxiliary (helping) verb** | A small verb put in front of a main verb to build a tense, a question or a negative | *be*, *have*, *do*, and the modals |
| **modal verb** | A helping verb that adds an attitude — how possible, how necessary, how polite | *can*, *must*, *should*, *will*, *might* |
| **infinitive** | The base form of a verb, usually with *to* | *to decide* |
| **bare infinitive** | The base form **without** *to* | *decide* (as in *must decide*) |
| **-ing form / gerund** | The *-ing* form of a verb, used where a noun could go | *Swimming is cheap.* |
| **past participle** | The form used after *have* and in passives; regular verbs end *-ed*, many common verbs are irregular | *decided*, *taken*, *written* |
| **tense** | The verb form that locates something in time — present, past | *works* / *worked* |
| **aspect** | The verb form that says how the action is viewed: finished, in progress, connected to now | simple / continuous / perfect |
| **simple** | The plain form, no *be + -ing*, no *have + participle* | *She works.* |
| **continuous (progressive)** | *be* + *-ing*. The action is seen as in progress and temporary | *She is working.* |
| **perfect** | *have* + past participle. The action is seen from a later point, looking back | *She has worked.* |
| **subject** | Who or what the sentence is about, and what the verb agrees with | **The council** approved it. |
| **object** | Who or what receives the action | The council approved **the plan**. |
| **transitive verb** | A verb that can take an object | *build*, *approve*, *see* |
| **intransitive verb** | A verb that cannot take an object | *arrive*, *happen*, *rise*, *fall* |
| **clause** | A group of words with its own subject and verb | *because prices rose* |
| **main (independent) clause** | A clause that could be a sentence on its own | *Prices rose.* |
| **subordinate (dependent) clause** | A clause that cannot stand alone; it is attached to a main clause | *because prices rose* |
| **countable noun** | A thing you can count; it has a plural | *a chair, two chairs* |
| **uncountable noun** | A thing English treats as a mass; no plural, no *a/an* | *information, advice, research* |
| **determiner** | A word before a noun that says which or how much | *a, the, this, some, my, every* |
| **article** | The three-way determiner system: *a/an*, *the*, or nothing at all | *a dog / the dog / dogs* |
| **quantifier** | A determiner of amount | *much, many, a few, plenty of* |
| **relative clause** | A clause that describes a noun, usually starting *who / which / that* | the report **that arrived late** |
| **active voice** | The subject does the action | *The committee rejected the bid.* |
| **passive voice** | The subject receives the action | *The bid was rejected.* |
| **register** | How formal or informal the language is, and whether it belongs in speech or writing | *kids* vs *children* vs *minors* |
| **hedge** | A word that softens a claim so it is not an over-statement | *tend to, may, in most cases* |

### 0.4 The four questions that resolve most choices in English

Almost every decision in this file is one of four questions wearing different clothes. Teaching the
four questions once, at the front of the Theory section, and then pointing back at them from every
chapter, is worth more than teaching sixty separate rules.

1. **WHEN? — Where does this sit in time, and is that time finished?**
   Resolves: present simple vs continuous, past simple vs present perfect, past simple vs past
   perfect, all the future forms, *since* vs *for*, *during* vs *while*, *by* vs *until*.
2. **HOW SURE / HOW STRONG? — How certain am I, and how hard am I pushing?**
   Resolves: every modal decision, the conditionals, hedging, *must/may/might/can't* for deduction.
3. **WHAT IS THIS SENTENCE ABOUT? — Which thing do I want in the subject position?**
   Resolves: active vs passive, cleft sentences, fronting, *there is* vs a plain subject.
4. **DOES MY READER ALREADY KNOW WHICH ONE I MEAN?**
   Resolves: *a* vs *the* vs zero, defining vs non-defining relative clauses, *some* vs *any*,
   pronoun choice, *another / the other*.

A fifth question sits over the top of all four and is not about meaning at all:

5. **WHO AM I TALKING TO, AND AM I WRITING OR SPEAKING?** — the register decision (§25).

### 0.5 What counts as a "genuine" decision — the inclusion test

A pair earned a place below only if **both** of these are true:

- both forms are grammatical English, so the learner cannot resolve it by asking "is this correct?";
- choosing wrongly changes the meaning, the truth, or the register in a way a competent reader
  notices.

Pairs that fail the test are listed in §24 as *non-decisions* — things learners agonise over that do
not matter — because deleting a worry is as useful as adding a rule, and `02-what-moves-a-band.md`
§5 makes that argument at length. Do not let a chapter spend a page on *which* vs *that* and half a
page on past simple vs present perfect.

## 1. THE PRESENT: present simple vs present continuous

### 1.1 The core decision

**Ask yourself:** *Am I describing how things generally are, or what is going on around now?*

| Form | Use it when | Authored example |
|---|---|---|
| **Present simple** (`works`) | It is generally, repeatedly or permanently true; a habit; a fact; a state; a scheduled timetable; the rules of a system | `The library closes at nine.` `Coastal cities flood more often than inland ones.` |
| **Present continuous** (`is working`) | It is in progress right now, or temporary, or a current trend that is still moving; also an annoying repeated habit with *always* | `I'm working from home this month.` `House prices are rising again.` |

**Minimal pair.**
`She teaches at the university.` — that is her job.
`She's teaching at the university.` — a temporary arrangement; next term she may not be.
The sentence is the same; the second one has an end in sight.

Second pair, because the "trend" use is the one IELTS-style tasks reward:
`Fewer people commute by car.` — a stated fact about how things are.
`Fewer people are commuting by car.` — a change that is under way and not finished.

**Deciding factor:** **Permanent or repeated → simple. Temporary or in progress → continuous.**

**Trap / false rule.** The false rule taught almost everywhere is *"present continuous = now, present
simple = every day."* It breaks immediately on `House prices are rising` (not happening at this
instant) and on `The train leaves at 6` (a future event in the simple). The honest version is
**permanent vs temporary**, with *now* as the commonest special case of temporary.

**Register:** BOTH. Speaking Part 1 lives on this pair — `I usually cycle in` vs `I'm cycling more
at the moment` — and mixing them up is the fastest way to sound like a beginner in the first two
minutes of the test. In Academic Task 1 the present simple describes the chart and a process; the
continuous barely appears.

### 1.2 The state-verb boundary — the reason 1.1 is harder than it looks

Some verbs describe **states**, not actions: knowing, liking, owning, seeming. English normally puts
these in the simple even when they are true only right now, because a state has no "in progress".

**Ask yourself:** *Is this a thing I am doing, or a thing that is simply the case?*

| Group | Verbs | Normally simple | Comment |
|---|---|---|---|
| thinking/opinion | *know, believe, understand, mean, agree, doubt, realise, suppose* | `I know what you mean.` | ✗ `I am knowing` |
| liking/wanting | *like, love, hate, prefer, want, need, wish* | `She wants a refund.` | ✗ `She is wanting` |
| senses | *see, hear, smell, taste, feel* (when involuntary) | `I hear a noise.` | ✓ but see below |
| possession/relation | *have* (own), *own, belong, contain, consist of, include, depend on* | `The report contains three sections.` | ✗ `is containing` |
| being/seeming | *be, seem, appear, look* (= seem), *cost, weigh, measure* | `It seems unlikely.` | ✗ `is seeming` |

**The honest complication, which most courses hide.** Several of these verbs have **two meanings** —
a state meaning and an action meaning — and the action meaning takes the continuous perfectly well.
This is not an exception; it is the same rule applied to a different sense of the word.

| Verb | State meaning → simple | Action meaning → continuous |
|---|---|---|
| *have* | `They have two offices.` (own) | `They're having a meeting.` (an event) |
| *think* | `I think it's expensive.` (opinion) | `I'm thinking about moving.` (mental activity) |
| *see* | `I see the problem.` (understand) | `I'm seeing the supervisor at four.` (meeting) |
| *taste* | `The soup tastes salty.` (property) | `He's tasting the soup.` (deliberate act) |
| *look* | `She looks tired.` (appearance) | `She's looking at the figures.` (act of looking) |
| *feel* | `I feel it's a mistake.` (opinion) | `I'm feeling much better.` (state of health — **both are standard here**) |
| *be* | `He is careful.` (character) | `He's being careful.` (behaving that way just now) |

**Deciding factor:** **A state verb goes in the simple — unless the verb is being used for something
you are actively doing, in which case it is no longer a state verb.**

**Trap.** `I am understanding` / `I am wanting` / `I am knowing` are the classic errors, and they
come from over-applying 1.1 ("but it's true *now*!"). Name the over-generalisation explicitly.

**Register note, stated honestly:** the continuous of *love* and *like* is widespread in informal
speech and advertising (`I'm loving this weather`). Learners will hear it. It is real, current,
informal English, and it is **not** a form to use in Task 2. Say both halves.

### 1.3 Present simple for a future timetable

**Ask yourself:** *Is this fixed by a timetable, calendar or schedule that is not mine to change?*

| Form | Use it when | Example |
|---|---|---|
| Present simple | Scheduled events: transport, opening hours, programmes, courses | `The conference starts on Monday.` |
| Present continuous | A personal arrangement already fixed with another person | `I'm meeting the supervisor on Monday.` |

**Minimal pair:** `The train leaves at six.` (timetable) vs `I'm leaving at six.` (my arrangement).

**Deciding factor:** **Timetables take the present simple; personal diaries take the present
continuous.** Fuller treatment of the future is §4.

## 2. THE PAST vs THE PRESENT PERFECT — the most expensive decision in English

### 2.0 Why this one gets a section of its own

`02-what-moves-a-band.md` ranks tense choice against a stated time reference at #4 in the whole
module (§0) and lists it at #3 in the error frequency table (§4), with a specific note that it is one
of the few *local* errors that can turn **global** — because the sentence ends up contradicting the
time expression inside it. `I have visited Berlin in 2019` is not a slip a reader steps over; it
asserts two incompatible things about time in eight words.

There are three separate reasons this is the hardest choice in English for most learners, and a
chapter that does not name all three will not fix it:

1. **Both forms translate into most languages as one form.** Many L1s have a single past. There is
   no L1 slot for the distinction, so there is nothing to transfer — the learner is not choosing
   wrongly, they are not aware a choice exists.
2. **The rule is about the SPEAKER'S view of time, not about the event.** The same real-world event
   can take either form depending on whether the speaker is treating its time period as closed.
3. **The everyday explanation is wrong.** "Present perfect = recent past" is false (`Humans have
   always feared the dark`) and "past simple = long ago" is false (`I left ten seconds ago`).

### 2.1 The core decision

**Ask yourself:** *Is the time period I am talking about finished?*
Not the *action* — the **time period**.

| Form | Use it when | Authored example |
|---|---|---|
| **Past simple** (`fell`) | The time period is finished and usually stated or understood: *yesterday, in 2019, last year, when I was a student, at the time* | `Applications fell sharply in 2019.` |
| **Present perfect** (`has fallen`) | The time period includes now and is still open: *since, so far, over the last decade, this year, recently, ever, never, already, yet* — **or no time is mentioned at all** and the point is the present result | `Applications have fallen sharply since 2019.` |

**Minimal pairs — five, because this is the decision worth over-teaching.**

| Past simple | Present perfect | What changed |
|---|---|---|
| `I lived in Lisbon for three years.` | `I have lived in Lisbon for three years.` | Past: I don't live there now. Perfect: I still do. **This is a factual difference about the speaker's life, not a nuance.** |
| `Did you eat?` | `Have you eaten?` | Past: at a known finished mealtime. Perfect: at any point up to now — the usual question when you are about to offer food |
| `The company lost money last year.` | `The company has lost money this year.` | The year is over vs the year is still running |
| `She wrote three reports.` | `She has written three reports.` | Past: that job is done and closed. Perfect: three so far; there may be more |
| `Where did you put the keys?` | `Where have you put the keys?` | Both natural. The perfect keeps the focus on the present consequence — the keys are still missing |

**Deciding factor:** **Look at the time expression and let it decide. A finished time word forces the
past simple. `since` / `for` / `so far` / `yet` / no time word at all → present perfect.**

**The three-second test to ship to learners:** find the time expression in the sentence. If you can
put a full stop after it — *in 2019.* *last week.* *when I was twenty.* — the period is closed, and
the verb must be past simple. If the period is still running, the verb must be present perfect.
If there is no time expression, ask whether you care about the result now.

**Traps and false rules, all four of them:**

1. **`I have done X in 2019` / `yesterday` / `last year`.** The single commonest tense error in
   IELTS-style writing. Rule: **a finished-time adverbial and the present perfect cannot appear in
   the same clause.** (`I have visited Berlin in 2019` ✗ → `I visited Berlin in 2019` ✓ or
   `I have visited Berlin` ✓.)
2. **`Since 2015 the rate dropped.`** The mirror error. *Since* opens a period that reaches now, so
   the verb must be perfect: `Since 2015 the rate has dropped.`
3. **"Present perfect means recently."** No. It means *the period is open*. `Nobody has ever solved
   it` reaches back to the beginning of time.
4. **"Present perfect is more advanced, so use it more."** No. Over-using it produces errors 1 and 2
   in the same essay.

**Register:** BOTH, and it pays everywhere. Speaking Part 1 (`I've never really got into cooking`),
Part 3 comparisons across time (`Attitudes have shifted`), Academic Task 1 with an open end-date
(`Numbers have risen since 2015`), Task 2 background sentences.

### 2.2 The four jobs of the present perfect — the version to actually teach

The "open period" rule is the right rule, but learners need to recognise the four *contexts* where
it shows up. Naming them is what makes the rule usable at speed.

| Job | What it does | Typical signal words | Authored example |
|---|---|---|---|
| **1. Result now** | A past action whose present consequence is the point | *just*, or no time word | `The council has withdrawn the proposal.` (so it is no longer on the table) |
| **2. Experience** | Some time in your life up to now; when is irrelevant | *ever, never, before, twice, several times* | `I've never taken a test like it.` |
| **3. Unfinished** | Started in the past, still true | *since, for, all week, so far* | `They have run the scheme since 2011.` |
| **4. Recent news with present relevance** | Announcing something | *just, already, yet, recently, lately* | `Two of the three sites have already closed.` |

**Deciding factor:** **If the answer to "when?" is irrelevant, unknown, or still running, use the
present perfect. If the answer to "when?" is a closed time, use the past simple.**

### 2.3 The genuine British/American difference — say it out loud

This is one of the places where usage really varies, and hiding it makes a learner distrust the book
when they hear the other form.

| | British English | American English |
|---|---|---|
| with *just, already, yet* | Present perfect is the norm: `I've just finished.` `Have you finished yet?` | Past simple is common and standard: `I just finished.` `Did you finish yet?` |
| with *ever/never* about life experience | `Have you ever been to Peru?` | Both; perfect still usual |
| the "open period" rule itself | The same in both | The same in both |

**What to tell an IELTS-style learner:** the perfect version is accepted everywhere and never sounds
wrong; the past-simple version is standard American and is not an error either. **Use the perfect and
stop thinking about it.** Do not teach it as "the American form is wrong".

### 2.4 Present perfect vs present perfect continuous

**Ask yourself:** *Am I pointing at how much has been achieved, or at how long it has been going on?*

| Form | Use it when | Authored example |
|---|---|---|
| **Present perfect simple** (`has written`) | The result, the completion, the quantity. Also with state verbs, where the continuous is not available | `She has written four chapters.` `They have known each other for years.` |
| **Present perfect continuous** (`has been writing`) | The activity and its duration; often still going on; often explaining a visible present state | `She has been writing all morning.` `Prices have been rising steadily.` |

**Minimal pairs:**

| Simple | Continuous | What changed |
|---|---|---|
| `I've read the report.` | `I've been reading the report.` | Simple: finished it. Continuous: still in it |
| `They've built forty units.` | `They've been building for two years.` | Simple counts the output. Continuous measures the effort |
| `He's cleaned the kitchen.` | `He's been cleaning the kitchen.` | Simple: it is clean now. Continuous: that is why he is covered in dust |

**With `for` and `since`, both are often possible and the difference is small:**
`I've worked here for five years.` ≈ `I've been working here for five years.`
Genuinely near-identical; the continuous feels slightly more temporary and slightly more personal.
Say so, rather than inventing a distinction.

**Deciding factor:** **Simple = how much / how many, and it is done. Continuous = how long, and it may
not be.**

**Traps:**
- **State verbs have no continuous.** ✗ `I have been knowing her since 2010.` → `I have known her…`
- Never use the continuous with a completed quantity: ✗ `I've been writing four chapters.`
- The continuous does not mean "more advanced". In Academic Task 1 the simple is usually right,
  because the task is about how much changed, not about the duration of the changing.

**Register:** BOTH. The continuous is more frequent in speech than in academic writing.

## 3. THE PAST: four forms, three decisions

### 3.1 Past simple vs past continuous

**Ask yourself:** *Is this an event on the timeline, or the background the events happen against?*

| Form | Use it when | Authored example |
|---|---|---|
| **Past simple** (`arrived`) | A completed event; the next thing that happened; the spine of a story; a past state | `The results arrived on Thursday.` |
| **Past continuous** (`was arriving`) | Something in progress at a past moment; the longer situation that a shorter event interrupts; two things going on at once; background scene-setting | `We were still unpacking when the call came.` |

**Minimal pairs:**

| A | B | What changed |
|---|---|---|
| `When the manager arrived, they left.` | `When the manager arrived, they were leaving.` | A: they left *after* she arrived (sequence). B: the leaving was already under way (overlap) |
| `I read the report on the train.` | `I was reading the report on the train.` | A: I finished it. B: no claim that I finished |
| `She cooked while I laid the table.` | `She was cooking while I was laying the table.` | Nearly the same; the continuous version foregrounds the two activities running in parallel |

**Deciding factor:** **Short, finished, moves the story forward → past simple. Longer, unfinished,
sets the scene → past continuous.**

**The `when` / `while` pattern to teach as a frame** (it is worth a whole chapter box):
`While + past continuous, past simple.` — `While I was waiting, the power went out.`
`Past continuous + when + past simple.` — `I was waiting when the power went out.`

**Traps:**
- Putting the whole narrative in the continuous. The continuous is the frame, not the picture.
- State verbs again: ✗ `I was knowing the answer.`
- `used to` is not a substitute for the past continuous (§10).

**Register:** BOTH; heaviest payoff in Speaking Part 2, where the four narrative tenses across two
minutes is the clearest structure-to-task mapping in the exam
(`02-what-moves-a-band.md` §6.5).

### 3.2 Past simple vs past perfect

**Ask yourself:** *Do I need to show that this happened BEFORE another past thing I have already
mentioned?*

| Form | Use it when | Authored example |
|---|---|---|
| **Past simple** (`left`) | Events in the order they happened | `She read the email and called him.` |
| **Past perfect** (`had left`) | One past event needs to be marked as earlier than another past event already in play — you are stepping backwards in the story | `By the time she called, he had already left.` |

**Minimal pair — this is the pair that proves the past perfect earns its keep:**
`When I arrived, they left.` — I arrived; then they left. (Possibly because I arrived.)
`When I arrived, they had left.` — they left first; I found an empty room.
Same eight words, opposite events.

Another: `The committee approved the plan the board rejected.` vs `The committee approved the plan the
board had rejected.` — the second makes the order unambiguous.

**Deciding factor:** **The past perfect exists only to put one past event BEFORE another past event.
No second past event, no past perfect.**

**When the past perfect is optional — say this, because it stops the over-use:**
If *before* or *after* already makes the order clear, the past simple is fine and often more natural:
`After she resigned, the department was restructured.` ✓ (`had resigned` also ✓, no gain.)

**Traps:**
1. **Past perfect as decorative past.** `Last year I had gone to Istanbul and I had visited three
   museums.` Nothing is being sequenced; it reads as a structure deployed for show, which is worse
   than the past simple it replaced. Flagged at §3.2 item 6 of `02-what-moves-a-band.md`.
2. **Past perfect for "a long time ago".** It does not mean that. It means *before that other thing*.
3. Only the first verb needs it: `He had finished the report and sent it` is fine; `had sent` is not
   required.

**Register:** BOTH. High value in Speaking Part 2 (one deliberate `had` in a narrative) and in GT
letters explaining a past reason. Tier B in the risk table — good value, medium risk.

### 3.3 Past perfect vs past perfect continuous

**Ask yourself:** *Before that past point — do I mean the finished achievement, or how long it had
been going on?*

| Form | Use it when | Authored example |
|---|---|---|
| **Past perfect simple** (`had worked`) | Completed before a past point; quantity; state verbs | `She had submitted three applications before the deadline.` |
| **Past perfect continuous** (`had been working`) | Duration up to a past point, often explaining a past situation | `She had been applying for months, and it showed.` |

**Minimal pair:** `He had run` (a completed run) vs `He had been running` (which is why he was out of
breath).

**Deciding factor:** **Same simple/continuous logic as §2.4, moved one step further back in time.**

**Register:** BOTH, but low frequency. Tier B at best; one instance in a Speaking Part 2 answer is a
strong range signal, four is a tic.

### 3.4 Past simple vs present perfect vs past perfect — the three-way summary

Learners confuse these in pairs, but they need one picture of all three:

| Form | Where the "now" of the sentence is | Authored example |
|---|---|---|
| Past simple | The event is in closed past time | `The scheme closed in 2018.` |
| Present perfect | The event is inside a period that reaches the present | `The scheme has closed.` (it is closed now) |
| Past perfect | The event is before another past event | `By 2020 the scheme had closed.` |

**Deciding factor:** **Past simple = closed time. Present perfect = time reaching now. Past perfect =
time before a past reference point.**

## 4. THE FUTURE: five forms and one decision tree

English has no future tense in the way it has a past tense. It has several present-tense structures
pressed into future service, and choosing among them is about **what kind of future** you mean:
a prediction, an intention, an arrangement, or a timetable.

### 4.1 The main four

**Ask yourself, in this order:**
1. *Is it fixed by a timetable?* → present simple
2. *Have I already arranged it with another person?* → present continuous
3. *Have I already decided it, or can I see the evidence for it right now?* → going to
4. *Am I deciding it as I speak, predicting, promising, offering or refusing?* → will

| Form | Use it when | Authored example |
|---|---|---|
| **will** | Prediction with no present evidence; a decision made at the moment of speaking; promises, offers, refusals; the neutral future in formal writing | `I think prices will keep rising.` `Fine — I'll call them.` |
| **going to** | An intention you already had before you spoke; a prediction based on evidence you can see now | `We're going to appeal the decision.` `Look at that sky — it's going to pour.` |
| **present continuous** | A definite arrangement, usually with a time and another person involved | `I'm meeting the landlord on Tuesday.` |
| **present simple** | Timetables, schedules, programmes | `The course starts in October.` |

**Minimal pairs — four, because each contrast is a different distinction:**

| A | B | What changed |
|---|---|---|
| `I'll help you move.` | `I'm going to help you move.` | A: I am deciding right now, as an offer. B: it was already planned |
| `It will rain.` | `It's going to rain.` | A: a prediction from belief or forecast. B: a prediction from present evidence — I can see the clouds |
| `I'm going to see the dentist.` | `I'm seeing the dentist at four.` | A: my intention. B: an appointment that exists in a diary |
| `The meeting starts at nine.` | `The meeting is starting.` | A: the schedule. B: it is beginning right now |

**Deciding factor:** **Timetable → present simple. Diary → present continuous. Already decided or
visible evidence → going to. Deciding now, or just predicting → will.**

**Traps and honest complications:**
- **`will` and `going to` overlap a great deal**, and in ordinary speech either is usually
  acceptable for a prediction. The distinction is real but soft. Do not mark a learner's `will` as
  an error when `going to` would be more natural — say "more natural", not "wrong".
- ✗ `I will meet the landlord on Tuesday` for a fixed appointment is not wrong, just less natural.
- **`going to` is informal in writing.** In Task 2 use `will`, `is likely to`, `is expected to`,
  `is projected to`. `Gonna` is speech only, and even in Speaking it is a pronunciation, not a
  spelling — never write it.
- **In an `if`-clause and after `when / as soon as / until / before / after`, English uses a present
  form for future time**: `If it rains, we'll cancel.` ✗ `If it will rain…`. See §5.2.
- ✗ `I will going to` — a form blend, not a choice error.

**Register:**
- Task 2 and Academic Task 1 projections: `will`, `is likely to`, `is expected to`, `is projected
  to`. Hedged futures buy Task Response credit at the same time (`02-what-moves-a-band.md` §6.1,
  §6.3).
- Speaking: all four, plus `going to` heavily; the absence of contractions (`I will` rather than
  `I'll`) sounds memorised.

### 4.2 The other future forms, and when they are worth the risk

| Form | Meaning | Authored example | Verdict |
|---|---|---|---|
| **future continuous** `will be working` | In progress at a future time; also a neutral, non-pushy way to ask about plans | `This time next week I'll be sitting the exam.` | Useful, low risk, genuine range marker |
| **future perfect** `will have finished` | Finished before a future point | `By 2030 the fund will have run out.` | One per essay maximum; pairs well with `By + date` |
| **future perfect continuous** `will have been working` | Duration up to a future point | `By June she'll have been teaching for twenty years.` | Rare; low payoff |
| **be about to** | On the point of happening | `The scheme is about to be reviewed.` | Useful and safe |
| **be to + infinitive** `The minister is to visit` | Formal/official arrangement — the register of news reporting | `A new levy is to be introduced next year.` | Formal writing only; impressive but easy to over-reach |
| **be due to** | Scheduled | `The report is due to be published in May.` | Safe and useful in Task 1 |

**Deciding factor:** **`will be doing` for "in progress then"; `will have done` for "finished by
then"; everything else is register decoration — take it only if the meaning needs it.**

### 4.3 Talking about the future from a past point ("the future in the past")

**Ask yourself:** *Am I reporting what was going to happen, from a viewpoint in the past?*

| Form | Example |
|---|---|
| `was going to` | `We were going to appeal, but the deadline passed.` (often implies it did not happen) |
| `would` | `She said she would call.` |
| past continuous | `I was leaving the next morning, so I packed.` |
| `was about to` | `He was about to sign when the offer was withdrawn.` |

**Deciding factor:** **Shift every future form one step into the past: `will` → `would`, `am going
to` → `was going to`, `am meeting` → `was meeting`.**

## 5. CONDITIONALS: which "if" sentence

### 5.0 Reframe the numbers before you teach them

The traditional presentation is a numbered list — zero, first, second, third — and it is the wrong
frame, because the number is a label for a *form* and the learner's actual problem is a *meaning*
choice. `02-what-moves-a-band.md` §9 item 3 says this explicitly: reframe the conditional decision as
**"how likely do I think this is, and is it about the past?"**, not as a numbered list.

Teach the numbers as an index, not as the explanation. Two questions resolve every conditional:

1. **Is this about the past, and did it not happen?** → third conditional.
2. **If not: how real is it?** Automatic → zero. Likely → first. Imaginary → second.

### 5.1 The four types side by side

| Type | The `if`-clause | The main clause | Meaning | Authored example |
|---|---|---|---|---|
| **Zero** | present simple | present simple | Always true; automatic result. `if` ≈ `whenever` | `If demand falls, prices drop.` |
| **First** | present simple | `will` + bare infinitive | A real, likely future possibility | `If demand falls, prices will drop.` |
| **Second** | past simple | `would` + bare infinitive | Imaginary, unlikely, or contrary to present fact | `If demand fell, prices would drop.` |
| **Third** | past perfect | `would have` + past participle | The past, imagined differently — it did not happen | `If demand had fallen, prices would have dropped.` |

### 5.2 The decisions, one pair at a time

**Zero vs first — *Ask yourself: is this a general law, or one particular future occasion?***
`If you heat water to 100°C, it boils.` — always, every time.
`If you heat the water, it will boil.` — this water, this time.
**Deciding factor: `if` means `whenever` → zero. `if` means `on that one occasion` → first.**

**First vs second — *Ask yourself: do I actually think this might happen?***
`If the council raises fares, ridership will fall.` — a real proposal on the table.
`If the council raised fares, ridership would fall.` — I am imagining it; I do not expect it, or I am
distancing myself from it.
**Deciding factor: real possibility → first. Imaginary or unlikely → second.**
Note honestly: the second conditional is also the **polite/tentative** version, which is why it is
used for suggestions even when the thing is perfectly possible (`If you took the earlier train, you'd
avoid the queue`). Distance in tense is distance in commitment, not only in likelihood.

**Second vs third — the pair the user asked for by name.**

**Ask yourself:** *Is the thing I am imagining still open, or is it already over?*

| | Second conditional | Third conditional |
|---|---|---|
| Time | Now or the future | The past, finished |
| Truth | Not true now, but conceivable | Definitely did not happen |
| Form | `If + past simple, would + verb` | `If + past perfect, would have + past participle` |
| Example | `If I lived closer, I'd cycle in.` | `If I had lived closer, I'd have cycled in.` |
| What it does in an answer | Speculation, proposal, hypothesis | Regret, hindsight, counterfactual explanation |

**Minimal pair:**
`If she took the job, she'd move to Leeds.` — the offer is open; she is deciding.
`If she had taken the job, she'd have moved to Leeds.` — she turned it down; this is what did not
happen.
**Deciding factor: second = imagining the present or future. Third = rewriting a past that is
already fixed.**

**Mixed conditionals — teach them as a meaning, flag them as optional.**
The two halves can sit in different times:
- past condition → present result: `If she had taken the job, she'd be living in Leeds now.`
- present condition → past result: `If he weren't so cautious, he would have signed months ago.`

These are correct and genuinely useful, but `02-what-moves-a-band.md` puts them in Tier C: the credit
over a plain second conditional is small and the failure mode is tense soup. **Theory should explain
them (it is a reference book, and a learner who meets one in a reading passage needs to parse it);
the practice module should not push a band-6 learner to produce them.**

### 5.3 The traps, ranked by how often they cost marks

1. **`would` inside the `if`-clause.** ✗ `If the council would reduce fares, more people would use
   the buses.` → `If the council reduced fares…`. **Rule to ship: `would` lives in the main clause
   only.** This is the #1 conditional error and it is worth a whole board.
   *Honest exception, flagged as advanced:* `will/would` can appear after `if` when it means
   *willingness* or a polite request — `If you would take a seat, someone will be with you shortly.`
   Mention it so learners who meet it are not confused; do not drill it.
2. **`will` in the `if`-clause of a first conditional.** ✗ `If it will rain, we'll cancel.` The same
   rule covers `when, as soon as, before, after, until, unless`: present form, future meaning.
3. **Second and third mixed by accident.** ✗ `If I would have known, I would tell you.` Two errors.
4. **`was` vs `were` in the second conditional.** Both are used. `If I were you` is the fixed,
   fully-standard formal form and is the safe choice in writing; `If I was you` is extremely common
   in informal speech and is not an error in that register. **Say both; recommend `were` for
   writing.** This is a real variation, not a rule.
5. **Forgetting the comma.** When the `if`-clause comes first, a comma follows it: `If demand falls,
   prices drop.` When it comes second, no comma: `Prices drop if demand falls.`

### 5.4 The `if`-family: which conjunction

| Word | Meaning | Authored example | The trap |
|---|---|---|---|
| **if** | on this condition | `If the funding arrives, we'll expand.` | — |
| **unless** | except if / if not | `We'll close unless the funding arrives.` | ✗ `unless the funding doesn't arrive` — *unless* is already negative. **Never use `unless` with a negative verb.** |
| **as long as / provided (that) / providing** | on the strict condition that | `We'll proceed provided the survey is clear.` | `provided that` is formal; `as long as` is neutral |
| **in case** | as a precaution, in advance | `Take the receipt in case they query it.` | ✗ confusing it with `if`. `I'll take an umbrella if it rains` = I'll only take it when I see rain. `…in case it rains` = I'll take it now, just in case |
| **even if** | it makes no difference | `Even if the funding arrives, the site is unsuitable.` | — |
| **whether** | either way | `We'll decide whether to appeal.` | *whether*, not *if*, before *to* + verb and after a preposition |
| **suppose / supposing / what if** | inviting speculation, informal | `Suppose the grant fell through — what then?` | speech and informal writing |

**Deciding factor:** ***unless* = "except if", so it never takes another negative. *in case* is
advance precaution, not a condition.**

### 5.5 The rest of the unreal-past family — `wish`, `if only`, `it's time`, `would rather`

These all use a past form to talk about something unreal. Grouping them with the conditionals is what
makes them make sense, and no learner ever gets told they are the same system.

| Structure | Time it refers to | Authored example | Meaning |
|---|---|---|---|
| `wish` + past simple | now | `I wish I lived closer.` | I don't, and I regret it |
| `wish` + `could` | now, ability | `I wish I could help.` | I can't |
| `wish` + past perfect | the past | `I wish I had applied earlier.` | I didn't, and I regret it |
| `wish` + `would` | someone else's annoying behaviour, or a change you want | `I wish they would publish the figures.` | complaint / desire for change; **not used for your own actions** — ✗ `I wish I would…` |
| `if only` | same as `wish`, stronger | `If only we had booked earlier.` | more emotional |
| `It's time` + past simple | now | `It's time we left.` | we should have gone already |
| `would rather` + past simple (different subject) | now/future | `I'd rather you didn't mention it.` | preference about someone else |
| `would rather` + bare infinitive (same subject) | now/future | `I'd rather wait.` | own preference |
| `as if / as though` + past | unreal comparison | `He talks as if he owned the place.` | he doesn't |

**Minimal pair:** `I wish I knew.` (I don't know — now) vs `I wish I had known.` (I didn't know — at
the time). One word of difference; two different regrets.

**Deciding factor:** **The unreal past: step the verb one tense backwards, and the sentence becomes
"not true".**

**Register:** BOTH. `wish` + past perfect is a very strong Speaking Part 2 move for a "describe a
time you…" card; `It's time we…` and `would rather` are natural in Part 3.

## 6. MODALS 1: obligation and necessity

### 6.0 The map first

Modals are the **how sure / how strong** question (§0.4 question 2). Almost every modal decision is a
position on a scale, and drawing the scale once is worth more than twenty separate definitions.

```
OBLIGATION   must / have to  >  should / ought to  >  could  >  (no modal)
             you have no      it's a good           it's an    just a fact
             choice           idea                  option
```

### 6.1 `must` vs `have to`

**Ask yourself:** *Whose rule is this — mine, or someone else's?*

| Form | Use it when | Authored example |
|---|---|---|
| **must** | The obligation comes from the speaker or writer: rules you are stating, your own strong recommendation, notices and regulations | `Applicants must submit two references.` `I must remember to renew it.` |
| **have to** | The obligation comes from outside: circumstances, other people, the law, the facts | `I have to be there by nine — it's in the contract.` |

**Minimal pair:**
`I must give up coffee.` — I have decided; nobody is making me.
`I have to give up coffee.` — the doctor told me.
The difference is who is imposing the rule.

**Deciding factor:** **`must` = the rule is mine. `have to` = the rule is someone else's.**

**Honest complications that a reference book must state:**
- The distinction is a **tendency**, not a hard rule, and speakers break it constantly.
- **`must` for obligation is much rarer in speech than `have to`**, and it is rarer in American
  English than in British English. In conversation `have to` and `have got to` do nearly all the
  work.
- **`must` has no past and no future form for obligation.** Use `had to` and `will have to`.
  ✗ `Yesterday I must go.` → `Yesterday I had to go.` (`must have gone` means something completely
  different — see §8.)
- **`have got to`** (`I've got to leave`) is informal, chiefly British, spoken. Fine in Speaking,
  wrong in Task 2.
- **`need to`** is the softest of the three and is often the most natural in modern writing:
  `Governments need to act.`
- ✗ **`must to`** — a very common form error, over-generalised from `have to` / `ought to`.
  Modals take the bare infinitive.

**Register:** `must` is at home in formal written rules and in Task 2 recommendations — but see the
warning in §6.3: `must` for every recommendation reads as shouting and over-generalises, which is
exactly the band-7 Task Response residue.

### 6.2 `mustn't` vs `don't have to` — a meaning REVERSAL, not a nuance

This is the single most important negative in the modal system, and it must be taught as a warning,
not as a footnote.

| Form | What it means | Authored example |
|---|---|---|
| **mustn't** | It is forbidden. Do not do it. | `You mustn't share the login.` |
| **don't have to** | It is not necessary. Do it or don't — your choice. | `You don't have to share the login.` |

**Minimal pair — the whole section in two lines:**
`You mustn't tell them.` = it is prohibited.
`You don't have to tell them.` = it is optional.
**These are near-opposites in the same six words.**

**Deciding factor:** **`mustn't` = prohibition. `don't have to` = no obligation. The negative of
`must` is NOT `don't have to`.**

**Related negatives, so the whole set is in one place:**

| Form | Meaning |
|---|---|
| `can't` | not allowed / not possible |
| `may not` | not permitted (formal) |
| `needn't` / `don't need to` | not necessary (same as `don't have to`) |
| `shouldn't` | it's a bad idea |
| `had better not` | strong warning about a consequence |

**Register:** BOTH. `mustn't` is chiefly British; American English tends to `can't` or `may not` for
prohibition. `needn't` is British and slightly formal; `don't need to` is universal.

### 6.3 `should` vs `ought to` vs `had better` vs `be supposed to`

**Ask yourself:** *Am I giving general advice, or warning about a specific bad outcome?*

| Form | Use it when | Authored example |
|---|---|---|
| **should** | Ordinary advice, recommendation, expectation. The default | `Students should keep a copy of every submission.` |
| **ought to** | Almost identical to `should`, very slightly more about an outside standard or duty; much less frequent | `We ought to have replied by now.` |
| **had better ('d better)** | Strong, urgent advice about **one specific situation**, with an implied bad consequence if ignored | `You'd better keep the receipt — they will ask for it.` |
| **be supposed to** | What is expected or arranged, often with a hint that reality differs | `The results were supposed to arrive on Friday.` |

**Minimal pair:**
`You should back up your files.` — sensible general advice.
`You'd better back up your files.` — something bad is about to happen if you don't.
`had better` is not a politer or stronger `should`; it is a **warning**.

**Deciding factor:** **`should` = general advice. `had better` = this time, or else. `ought to` = the
same as `should`, and you may safely never use it.**

**Traps:**
- ✗ `had better to` — it takes the bare infinitive: `had better go`.
- `had better` looks past-tense but refers to **now or the future**.
- Negative: `had better not go` (not ✗ `hadn't better`).
- `should` also has a non-advice meaning — **expectation**: `The parcel should arrive tomorrow`
  means "I expect it to". Learners meet this and think it is a mistake.
- **Do not use `must` where `should` is meant.** `Students must study harder` as advice reads as an
  order and over-claims; `should` is the correct strength. Flagged in `02-what-moves-a-band.md`
  §4 item 14.

**Register:** `should` — BOTH, and the workhorse of Task 2 recommendation sentences. `had better` —
SPOKEN, and informal enough that it is a poor fit for a Task 2 essay. `ought to` — BOTH but rare.
`be supposed to` — SPOKEN and informal writing.

### 6.4 The strength-of-recommendation scale for Task 2

`02-what-moves-a-band.md` §6.3 makes this a two-criteria lesson: modality is scored in GRA *and*
fixes the over-generalisation that costs Task Response at band 7. The scale, from strongest to
weakest, with what each one commits you to:

| Strength | Form | Authored example | What it commits you to |
|---|---|---|---|
| Strongest | `must` / `it is essential that` | `Regulators must be given power to impose fines.` | An absolute claim you now have to defend |
| Strong | `should` / `need to` / `it is important that` | `Regulators should publish the data quarterly.` | A clear position — the Task 2 default |
| Moderate | `could` / `might` / `one option would be to` | `Councils could trial the scheme in two boroughs first.` | A suggestion among others |
| Hedged claim | `tend to` / `is likely to` / `in most cases` / `broadly` | `Charges of this kind tend to fall hardest on low earners.` | A generalisation you have protected |
| Weakest | `may` / `it is possible that` | `The effect may be smaller than supporters claim.` | Bare possibility |

**Deciding factor:** **Vary the strength across the essay. `should` eleven times is not a position;
it is a tic — and `must` eleven times is an over-claim.**

## 7. MODALS 2: ability, permission, requests, possibility

### 7.1 `can` vs `could` vs `be able to`

**Ask yourself:** *Is this present ability, past ability, a single past success, or a form the tense
system cannot build?*

| Form | Use it when | Authored example |
|---|---|---|
| **can** | Present ability; general possibility; informal permission; informal requests | `She can read three languages.` |
| **could** | (a) Past general ability; (b) present *possibility* (see §7.3); (c) a politer request | `He could swim before he could walk.` `Could you send the file?` |
| **be able to** | Any tense a modal cannot reach — perfect, infinitive, future, after another modal — and a **single past success** | `They have been able to reduce waiting times.` `We will be able to confirm on Monday.` |

**The past-ability split, which almost every learner gets wrong:**

| Situation | Correct form | Authored example |
|---|---|---|
| General ability over a period in the past | `could` | `At that age I could run for hours.` |
| **One specific occasion where you succeeded** | `was/were able to` or `managed to` | `Despite the strike, we were able to reach the airport on time.` ✗ `we could reach` |
| A specific occasion where you did **not** succeed | `couldn't` is fine | `We couldn't get a signal anywhere in the valley.` |

**Minimal pair:** `I could persuade him.` (I had the general capacity, or: it would be possible —
ambiguous) vs `I was able to persuade him.` (I actually did it, that one time).

**Deciding factor:** **`could` = general past ability. One-off past success = `was able to` /
`managed to`. Negative one-off failures may keep `couldn't`.**

**Traps:**
- ✗ `I can to swim` / ✗ `I will can` — modals take a bare infinitive and cannot stack. → `will be
  able to`.
- ✗ `can able to`.
- `be able to` is used with people and organisations; it is odd with inanimate subjects — `The
  machine can process 400 units an hour` ✓, `is able to process` is stiff.

**Register:** BOTH. For requests, the politeness ladder is worth a box of its own:
`Can you…` (informal) < `Could you…` (neutral–polite) < `Would you mind + -ing` (polite) <
`I would be grateful if you could…` (formal, and the correct register for a GT formal letter —
`02-what-moves-a-band.md` §6.2).

### 7.2 `can` vs `may` for permission

| Form | Register | Authored example |
|---|---|---|
| `can` | Neutral, and by far the commonest in speech | `Can I take one of these?` |
| `could` | Slightly more tentative | `Could I take one of these?` |
| `may` | Formal; also the register of written rules | `Visitors may use the west entrance.` |
| `might` | Very tentative, formal, chiefly British, rare | `Might I make a suggestion?` |

**Honest note:** the old prescriptive rule that `can` means only ability and `may` must be used for
permission is **not a rule of modern English** and has not been for a long time. `Can I…` is standard
in all but the most formal contexts. Say so; do not teach the myth.

### 7.3 `may` vs `might` vs `could` for possibility

**Ask yourself:** *How likely is it — and how formal am I being?*

| Form | Use it when | Authored example |
|---|---|---|
| **may** | A real possibility; slightly formal; the natural hedge in academic writing | `The increase may reflect a change in the reporting method.` |
| **might** | A real possibility, felt as slightly more remote by many speakers; neutral register | `The scheme might not survive the next budget.` |
| **could** | A possibility among several options; also "would be able to" | `Costs could fall if the subsidy is renewed.` |
| **may/might/could well** | Reinforced — a fairly strong possibility | `The subsidy may well have accelerated the decline.` |

**The honest statement of the difference:** `may` and `might` are very close, and the "might is less
likely" distinction is a tendency reported by many speakers rather than a firm rule. The **reliable**
differences are:
- `may` is more formal and is the more usual hedge in academic prose;
- `might` is the past/backshifted form of `may` in reported speech (`He said he might come`);
- `may not` and `might not` mean "possibly not"; **`could not` does not** — `couldn't` means
  impossible (§8), which is a real trap:
  `It may not be true.` = perhaps it isn't.
  `It can't be true.` = it is impossible.

**Deciding factor:** **`may` / `might` / `could` all mean "possibly". `may` is the formal one;
`could` adds "among other options"; and the negatives are NOT interchangeable.**

**Register:** `may` — WRITTEN, and the single most useful hedge in Task 2 and Task 1 causal language.
`might` — BOTH. `could` — BOTH, and the natural Speaking Part 3 speculation modal.

## 8. MODALS 3: deduction — `must` / `may` / `might` / `could` / `can't`

### 8.1 The present

**Ask yourself:** *How certain am I, on the evidence I have?*

| Certainty | Form | Authored example |
|---|---|---|
| ~100% sure it IS true | **must** | `The lights are on, so someone must be inside.` |
| Possible | **may / might / could** | `The delay may be weather-related.` |
| ~100% sure it is NOT true | **can't** (also `couldn't`) | `That can't be the final figure — it's higher than the total.` |

**The trap that defines this section:** the opposite of `must be` is **`can't be`**, never
`mustn't be`. `mustn't` is prohibition (§6.2) and has nothing to do with deduction.
`He must be at home.` ⟷ `He can't be at home.` ✗ `He mustn't be at home.`

**Deciding factor:** **Sure it's true → `must`. Sure it's false → `can't`. Anything in between →
`may / might / could`.**

### 8.2 The past — modal + `have` + past participle

The same scale, one step back. This is the structure `02-what-moves-a-band.md` places in Tier B and
recommends for careful causal language in Task 1 and Part 3.

| Certainty about the past | Form | Authored example |
|---|---|---|
| Sure it happened | `must have + past participle` | `The fall must have begun before the policy took effect.` |
| Possible | `may / might / could have + past participle` | `The subsidy may have contributed to the rise.` |
| Sure it did not happen | `can't have / couldn't have + past participle` | `They can't have known about the defect in 2015.` |

**Trap:** ✗ `may contributed`, ✗ `must been`. The form is **modal + have + past participle**, always,
with no `to`.

### 8.3 The other modal + perfect meanings, which are a different system

Learners meet these mixed together with §8.2 and cannot tell them apart. Put them in one table.

| Form | Meaning | Authored example |
|---|---|---|
| `should have + pp` | It didn't happen and that was a mistake — criticism or regret | `I should have applied earlier.` |
| `shouldn't have + pp` | It happened and that was a mistake | `They shouldn't have published the figures unchecked.` |
| `could have + pp` | It was possible but did not happen (a missed opportunity) — **or** a past possibility (§8.2) | `We could have taken the earlier flight.` |
| `would have + pp` | The result of an unreal past condition (third conditional, §5.1) | `I would have gone if I'd known.` |
| `needn't have + pp` | You did it, and it turned out to be unnecessary | `You needn't have queued — the tickets were emailed.` |
| `didn't need to + verb` | It was not necessary. **Whether you did it is not stated by the form** | `I didn't need to queue.` |

**On `needn't have` vs `didn't need to` — the honest version.** `needn't have + past participle`
reliably means *you did it and it was unnecessary*. `didn't need to` states only that the necessity
was absent; in British usage it often carries the implication that the action did not happen, but
that is an implication of context, not a fixed meaning of the form, and speakers do use it when the
action did happen. Teach the first as reliable and the second as "usually, but check the context".

**Minimal pair:** `You needn't have waited.` (you waited; it was pointless) vs `You didn't need to
wait.` (waiting wasn't required).

**Deciding factor:** **`must/may/can't + have` = deduction about the past. `should have` = regret.
`would have` = a conditional result. Same shape, three different systems.**

## 9. Modals in one summary table

Because a reference book needs one page a learner can photograph.

| Function | Weakest → strongest |
|---|---|
| Obligation | `could` → `should` / `ought to` → `need to` → `have to` → `must` |
| Prohibition | `shouldn't` → `had better not` → `can't` / `may not` → `mustn't` |
| No obligation | `don't have to` = `don't need to` = `needn't` |
| Possibility (present) | `might` → `may` → `could` → `should` (expectation) → `must` (deduction) |
| Impossibility | `can't` / `couldn't` |
| Ability | `can` (now) · `could` (past general) · `was able to` (past single occasion) |
| Advice | `could` → `should` / `ought to` → `had better` → `must` |
| Permission | `can` (informal) → `could` → `may` (formal) |
| Requests | `Can you` → `Could you` → `Would you mind -ing` → `I'd be grateful if you could` |
| Habit (past) | `used to` / `would` (§10) |

## 10. `used to` vs `would` vs past simple — and the two `used to`s

### 10.1 The past-habit decision

**Ask yourself:** *Was this a repeated action, a past state, or a single event?*

| Form | Use it when | Authored example |
|---|---|---|
| **used to + verb** | A past habit **or a past state** that is no longer true; the contrast with now is the point | `We used to live above the shop.` `He used to smoke.` |
| **would + verb** | A repeated past **action**, typically in a narrative or reminiscence with a time frame already set | `Every summer my grandfather would repaint the boat.` |
| **past simple** | A single completed event; also perfectly correct for habits when no contrast with now is intended | `We lived above the shop for six years.` |

**The rule that separates `used to` and `would`, and it is a hard one:**
**`would` cannot be used for states.** ✓ `I used to have a motorbike.` ✗ `I would have a motorbike.`
✓ `She used to be shy.` ✗ `She would be shy.` (That sentence means something else — a prediction.)

**Minimal pair:**
`I used to walk to work.` — I don't any more. The change is the message.
`I walked to work.` — on that occasion, or over that period; no claim about now.

**Deciding factor:** **`used to` for anything that was true then and isn't now. `would` only for
repeated actions, and only once the past time frame is established. States never take `would`.**

**Traps:**
- Questions and negatives: `Did you use to…?` / `didn't use to` — **no `d`** after `did`.
- ✗ `I am used to live there` when the past habit is meant — that is the other structure, §10.2.
- Starting a story with `would`: it needs a time frame first, or it reads as a conditional.
- `used to` has **no present form**. For present habits use the present simple with `usually`.

**Register:** BOTH; a very strong Speaking Part 1 and Part 3 move for "how things have changed"
(`People used to expect a job for life, whereas now nobody plans past five years`).

### 10.2 `used to do` vs `be used to doing` vs `get used to doing`

Three structures that look identical and mean entirely different things. This is a pure form-vs-
meaning trap and belongs in a warning box.

| Structure | Meaning | Authored example |
|---|---|---|
| `used to + bare infinitive` | A past habit or state, now finished | `I used to cycle everywhere.` |
| `be used to + -ing / noun` | Accustomed to; it feels normal to me now | `I'm used to cycling in the rain.` |
| `get used to + -ing / noun` | The process of becoming accustomed | `It took a month to get used to the commute.` |

**Minimal pair:** `I used to work nights.` (I don't now) vs `I'm used to working nights.` (I do, and
it's fine).

**Deciding factor:** **`used to` + base verb = the past. `be/get used to` + `-ing` = a feeling about
now. The `to` in the second pair is a preposition, which is why a verb after it takes `-ing`.**

## 11. ACTIVE vs PASSIVE — and the real reason to choose the passive

### 11.1 The decision nobody teaches

Most courses teach the passive as a **transformation drill**: take an active sentence, move the
object to the front, done. That teaches the form and leaves the learner with no idea when to use it —
so they either avoid it entirely or sprinkle it to look academic. `02-what-moves-a-band.md` §0 item 10
says explicitly: teach it as a **topic-choice decision**.

**Ask yourself:** *What is this sentence ABOUT? Whatever that is, put it in the subject position.*

| Voice | Use it when | Authored example |
|---|---|---|
| **Active** | The doer is the point, or the doer is interesting, or you are telling a story | `The council rejected the proposal.` |
| **Passive** | (a) The doer is unknown; (b) the doer is obvious or irrelevant; (c) you want to keep the **topic** in subject position across sentences; (d) the process matters more than the person; (e) you are being tactful or impersonal | `The proposal was rejected.` |

**The topic-continuity argument, with a worked example — this is the part to author carefully:**

> Bad (topic jumps): `The council introduced a congestion charge in 2019. Drivers on low incomes
> absorbed most of the cost, and researchers at two universities have since criticised the scheme.`
>
> Better (the scheme stays the subject): `A congestion charge was introduced in 2019. It was absorbed
> mainly by drivers on low incomes, and it has since been criticised by researchers at two
> universities.`

Nothing in the second version is fancier. It is easier to read because **each sentence starts with
what the paragraph is about**, and the passive is the tool that made that possible. That is the whole
justification for the passive, and once a learner has it they stop over-using it.

**Minimal pair on emphasis:**
`A power cut delayed the results.` — the sentence is about the power cut.
`The results were delayed by a power cut.` — the sentence is about the results.
Both true, both correct; they belong in different paragraphs.

**Deciding factor:** **Choose the voice that puts the paragraph's topic in the subject slot. If you
find yourself inventing a vague doer (`people`, `they`, `someone`) just to stay active, use the
passive.**

### 11.2 When the passive is required, not optional

| Context | Why | Authored example |
|---|---|---|
| Describing a **process** (Academic Task 1) | The agent is irrelevant and constant; the register of process description is passive | `The pulp is screened for contaminants before it is pressed into sheets.` |
| Describing a **map change** | There is no named agent | `The southern car park was replaced by a landscaped square.` |
| Academic and official writing generally | Depersonalises the claim | `Recycling targets have been revised downwards twice.` |
| When the doer is genuinely unknown | No alternative | `The files were removed some time before the audit.` |

**Honest qualification** (carried from `02-what-moves-a-band.md` §10.6): the heuristic "man-made
processes take the passive, natural processes take the active" is serviceable but not a rule —
natural-process descriptions frequently take the passive too (`the water is drawn up through the
roots`). Teach the reason (focus on the process, not the agent), so the learner can override it.

### 11.3 When NOT to use the passive

- **Speaking Part 2 personal narratives.** You are the agent; the passive removes you from your own
  story and sounds evasive.
- **When you have a position to state in Task 2.** `It is believed that…` hides whose belief it is.
  If it is yours, say so.
- **On intransitive verbs — this is an error, not a style problem.** ✗ `The number was increased
  sharply.` ✗ `The accident was happened.` ✗ `The population was risen.`
  **Test to ship: can the verb take an object? If not, there is no passive.** *(happen, arrive, rise,
  fall, occur, exist, appear, die, come, go* — no passive.)
- Chained passives that hide every actor for a whole paragraph. One nominalised, agentless sentence
  is register; four is unreadable.

### 11.4 `be`-passive vs `get`-passive

| Form | Register | Authored example |
|---|---|---|
| `be + past participle` | Neutral to formal; the default; the only one for writing | `The application was rejected.` |
| `get + past participle` | Informal, spoken; often something sudden, unwanted or accidental | `My application got rejected.` |

**Deciding factor:** **`get`-passive is spoken English. Never in Task 2.**

### 11.5 Passive reporting structures — the formal impersonal register

| Structure | Authored example | Use |
|---|---|---|
| `It is said/believed/thought/reported that…` | `It is widely believed that the scheme paid for itself.` | Attributing a view to nobody in particular |
| `Subject + is said/thought to + verb` | `The scheme is thought to have paid for itself.` | The same claim, more compact |
| `Subject + is said to have + pp` | `Emissions are estimated to have fallen by a fifth.` | Past version |

**Register:** WRITTEN, formal. Genuinely useful in Task 2 for reporting a common view before
disagreeing with it. Also very common in Reading passages, so learners need to *recognise* it even
if they never produce it.

### 11.6 The passive with two objects, and with a `by`-phrase

- Verbs with two objects give two possible passives: `They offered her the post.` →
  `She was offered the post.` (usual) / `The post was offered to her.` (also correct).
  **The person-first version is far more common.**
- **Include `by + agent` only when the agent adds information.** `The proposal was rejected by the
  planning committee` ✓ (informative). `The proposal was rejected by them` ✗ (say `They rejected the
  proposal`).

## 12. ARTICLES: `a` vs `an` vs `the` vs nothing

### 12.0 Why this is the biggest error category in the language

`02-what-moves-a-band.md` ranks articles/determiners #1 in the error table (§4) and #3 in the whole
module's payoff order (§0). The cause is stated there and is worth repeating in the chapter itself,
because it changes the learner's relationship to the problem: **many languages have no article
system at all** — Russian, Polish, Czech, Chinese, Japanese, Korean, Thai and Turkish among them —
so there is no slot in the learner's first language for the decision, and no amount of "listening
carefully" will supply one. It has to be built from rules.

The good news, also from that briefing: **three rules recover most of it, and the remaining fifth is
not worth the learner's time.** A theory chapter should say that out loud so the learner stops trying
to be perfect.

### 12.1 `a` vs `an` — a sound rule, not a letter rule

**Ask yourself:** *What SOUND does the next word start with — a consonant sound or a vowel sound?*

| Form | Rule | Authored examples |
|---|---|---|
| `a` | Before a consonant **sound** | `a university` (sounds like "yoo"), `a European partner`, `a one-way street` ("wun") |
| `an` | Before a vowel **sound** | `an hour` (the *h* is silent), `an MP` ("em"), `an honest answer` |

**Deciding factor:** **Say the next word out loud. The spelling is irrelevant.**

### 12.2 The core three-way decision

**Ask yourself, in this order:**
1. *Is the noun countable and singular?* → It **must** have a determiner. Never bare.
2. *Does my reader already know which one I mean?* → `the`. If not → `a/an`.
3. *Am I talking about the thing in general, not any particular one?* → usually **no article** with
   plurals and uncountables.

| Choice | Use it when | Authored example |
|---|---|---|
| **a / an** | First mention; one of many; a job or role; "any one of these" | `A new levy was introduced last year.` `She works as an auditor.` |
| **the** | The reader can identify which one: already mentioned; unique; specified by what follows; superlatives and ordinals; a known shared context | `The levy raised £40m.` `the first attempt`, `the highest figure`, `the cost of living` |
| **nothing (zero article)** | Generalisations with plural countables or uncountables; most proper nouns; some fixed phrases | `Renewable energy is getting cheaper.` `Governments should fund research.` |

**Minimal pairs — four, because each shows a different job of the article:**

| A | B | What changed |
|---|---|---|
| `I need a laptop.` | `I need the laptop.` | A: any laptop. B: a specific one we both know about |
| `Cars are getting heavier.` | `The cars are getting heavier.` | A: cars in general. B: a particular set of cars |
| `She went to school.` | `She went to the school.` | A: as a pupil (the institution's purpose). B: to the building, for some other reason |
| `He was in hospital.` (British) | `He was in the hospital.` | A: as a patient. B: physically in the building. **American English uses `in the hospital` for both** |

**Deciding factor:** **`a` introduces; `the` identifies; nothing generalises.**

### 12.3 The three ways English makes a generalisation — the decision the reference must cover

This is the single most under-taught article decision and it comes up in every Task 2 essay.

| Pattern | Register / feel | Authored example |
|---|---|---|
| **Bare plural** — the default | Neutral, and correct in almost every essay | `Electric vehicles are still expensive to insure.` |
| **`a/an` + singular** | "Any typical one of these" — good for definitions | `An electric vehicle costs more to insure than a petrol one.` |
| **`the` + singular** | Formal, technical, or about a class as an institution or invention | `The bicycle transformed working-class mobility.` |

Also: **`the` + adjective** for a whole group of people — `the elderly`, `the unemployed`, `the poor`.
Always plural in meaning: `The elderly are more affected.` (not ✗ `is`).

**Deciding factor:** **In an essay, generalise with a bare plural unless you have a reason not to.
`The + plural` is not a generalisation — it points at a specific group.**

**The classic error this fixes:** ✗ `In the modern society, the technology changes fast.` →
`In modern society, technology changes fast.`

### 12.4 The zero-article contexts worth listing

| Category | Zero article | But `the` when… |
|---|---|---|
| Meals | `before lunch` | `the lunch we were served` |
| Transport (`by`) | `by train, by car, on foot` | `on the train I took` |
| Institutions by purpose | `at university, in prison, at work, in bed` | you mean the building: `the university has a new library` |
| Languages, subjects, sports | `Arabic, economics, tennis` | `the economics of the scheme` |
| Most countries, cities, streets | `France, Lagos, Oxford Street` | plural/compound names: `the Netherlands, the United States, the Gulf` |
| Abstract nouns in general | `Trust takes years to build.` | specified: `the trust between the two agencies` |
| Years, months, days | `in March, on Friday, in 2019` | `the March of that year` |

**Register note:** `at university` / `in hospital` without the article is **British**; American English
says `at the university`, `in the hospital`. Both are correct English. Say so.

### 12.5 The three rules to ship

Straight from the payoff briefing, and they should appear as a boxed summary:

1. **A singular countable noun always needs a determiner** — `a`, `the`, `this`, `my`, `each`,
   something. It is never bare. (✗ `Government should act` → `Governments should act` or `The
   government should act`.)
2. **Generalisations take a bare plural or a bare uncountable.**
3. **Use `the` once the thing has been identified** — by earlier mention, by uniqueness, by a
   following phrase, or by a superlative/ordinal.

**Trap:** the over-correction. Once `the` is taught it goes everywhere. A chapter that teaches `the`
without teaching rule 2 makes the learner's writing worse.

## 13. QUANTIFIERS: how much, how many, and which word

### 13.1 `some` vs `any` (and `no`)

**Ask yourself:** *Is the sentence positive, and am I offering or requesting?*

| Form | Use it when | Authored example |
|---|---|---|
| **some** | Positive statements; **offers and requests**, where you expect "yes" | `There are some errors in the table.` `Would you like some help?` |
| **any** | Negatives and most questions; also "it doesn't matter which" in positives | `There aren't any errors.` `Do you have any questions?` `Any student can apply.` |
| **no** | A negative statement with a positive verb — more emphatic | `There are no errors in the table.` |

**Minimal pairs:**
`Would you like some coffee?` (an offer — I expect you to say yes) vs `Is there any coffee?` (a
genuine enquiry).
`Take any seat.` (whichever you like) vs `Take a seat.` (sit down).
`I didn't answer any questions.` (none) vs `I answered some questions.` (a few).

**Deciding factor:** **`some` = positive and offers. `any` = negative, question, or "it doesn't matter
which".**

**Trap:** ✗ `I don't have some money.` The rule about offers and requests does not extend to
negatives.

### 13.2 `much` vs `many` vs `a lot of` vs `plenty of`

**Ask yourself:** *Countable or uncountable — and is the sentence positive?*

| Form | Goes with | Register | Authored example |
|---|---|---|---|
| **many** | Plural countable | Neutral; fine in positives, questions and negatives | `Many households were affected.` |
| **much** | Uncountable | **Awkward in plain positive statements**; natural in negatives, questions, and after `so / too / as / how / very` | `There isn't much evidence.` `How much did it cost?` `too much traffic` |
| **a lot of / lots of** | Both | Informal to neutral; the everyday positive form | `A lot of people applied.` `lots of` is more informal |
| **plenty of** | Both | Informal-neutral; means "more than enough" | `There's plenty of space.` |
| **a great deal of / a large amount of** | Uncountable | Formal, written | `A great deal of research supports this.` |
| **a large number of / numerous** | Plural countable | Formal, written | `A large number of applicants withdrew.` |

**Minimal pair on register, not meaning:** `Much research supports this.` is grammatical but stiff and
rare; `A great deal of research supports this.` is the natural formal version; `Lots of research
supports this.` is the natural spoken version. **Same fact, three registers.**

**Deciding factor:** **Countable → `many`. Uncountable → `much`, but in a positive statement use
`a lot of` or a formal phrase instead.**

**Traps:**
- The uncountable nouns learners pluralise: ✗ `informations, advices, researches, equipments,
  furnitures, knowledges, evidences, feedbacks, staffs, softwares, homeworks, luggages, machineries,
  progresses, trainings`. Ship the counter phrases with them: `a piece of advice`, `an item of
  equipment`, `a body of research`, `a piece of information`.
  Honest footnote: `trainings` and `researches` do occur in some technical and institutional
  registers, and `staffs` and `softwares` occur in some regional varieties, so they are not
  universally wrong — but the safe advice for a learner is to treat all of these as uncountable.
- `amount of` + uncountable vs `number of` + countable: ✗ `the amount of students` → `the number of
  students`.
- `The number of X **is**` (singular) vs `A number of X **are**` (plural). This is a genuine trap and
  worth its own line.

### 13.3 `few` vs `a few` vs `little` vs `a little` — the article changes the sign

This is a decision where one tiny word reverses the attitude of the sentence.

| Form | Goes with | Meaning | Authored example |
|---|---|---|---|
| **a few** | Plural countable | Some — a small number, positive | `A few colleges have already adopted it.` (some have — good) |
| **few** | Plural countable | Not many — negative, disappointing | `Few colleges have adopted it.` (hardly any — bad) |
| **a little** | Uncountable | Some — a small amount, positive | `There is a little evidence for this.` (there is some) |
| **little** | Uncountable | Not much — negative | `There is little evidence for this.` (almost none) |

**Minimal pair — the pair that proves it:**
`A few students objected.` — some students objected; there was opposition.
`Few students objected.` — almost nobody objected; the policy went through.
**Opposite conclusions from one letter.**

**Deciding factor:** **With `a`, it's a positive "some". Without `a`, it's a negative "hardly any".**

**Register note, stated honestly:** bare `few` and `little` are somewhat formal. In speech people
usually say `not many` and `not much`. In Task 2, `few` and `little` are excellent — precise and
compact. In Speaking, `hardly any` is more natural.

**And the receptive payoff:** `02-what-moves-a-band.md` §6.7 notes that `few` vs `a few` points at
opposite answers in Reading completion tasks. This is not only a writing point.

### 13.4 `fewer` vs `less`

| Form | Traditional rule | Authored example |
|---|---|---|
| `fewer` | Countable | `fewer applicants`, `fewer cars` |
| `less` | Uncountable | `less funding`, `less traffic` |

**Honest statement of variation:** `less` with countables (`less people`, `less than ten items`) is
extremely common in speech and has been for centuries, and it is not a comprehension problem. But
`fewer` with countables is what careful written English uses and what an examiner expects in Task 2.
**Write `fewer`; do not lose sleep over hearing `less`.** Note also that `less` is standard with
measurements and amounts even when the noun looks countable: `less than five miles`, `less than ten
years`, because the measurement is treated as a quantity.

### 13.5 `all` vs `every` vs `each` vs `whole`

| Form | Use it when | Grammar | Authored example |
|---|---|---|---|
| **all** | The complete group, seen together | `all (of) the students`, `all students`, plural verb | `All students receive a login.` |
| **every** | 100% of them, seen one by one; general rules | `every` + **singular** noun + singular verb | `Every student receives a login.` |
| **each** | Individually, one at a time; often of a small or known set | `each` + singular noun + singular verb; can stand alone | `Each applicant was interviewed twice.` |
| **whole** | The entire single thing | `the whole + singular noun` | `The whole department was relocated.` |

**Minimal pair:** `All the rooms were checked.` (as a job) vs `Each room was checked.` (one by one,
individually) — same fact, different emphasis on the individuality.

**Traps:** ✗ `every students`, ✗ `all of students` (either `all students` or `all of the students`),
✗ `Every people`. `every` is singular in form even though it is 100% in meaning — and it takes a
singular verb, which is a subject–verb agreement trap.

### 13.6 `both` / `either` / `neither` / `none`

| Form | Number | Meaning | Authored example |
|---|---|---|---|
| `both` | 2, together | the two of them | `Both proposals were rejected.` |
| `either` | 2, one of them | one or the other | `Either option would work.` |
| `neither` | 2, zero | not one and not the other | `Neither option is affordable.` |
| `none` | 3+, zero | not any | `None of the proposals survived.` |

**Traps:** `neither` and `either` take a singular verb in careful writing (`Neither of the reports
is complete`), though a plural verb after `neither of` is very common in speech — say both. `none of`
takes either a singular or a plural verb and both are standard; the prescriptive "none = not one, so
singular" claim is not a rule of modern English. ✗ `Both of them isn't…` → `Neither of them is…`.

### 13.7 `other` / `another` / `the other` / `others`

| Form | Meaning | Authored example |
|---|---|---|
| `another` | One more, or a different one (singular, indefinite) | `We'll need another reviewer.` |
| `other` + plural | Additional or different ones, indefinite | `Other countries took the opposite view.` |
| `the other` | The remaining one, of a known set | `One site closed; the other stayed open.` |
| `the others` | The remaining ones | `Two applied; the others withdrew.` |
| `others` | Some more, indefinite | `Some agreed; others did not.` |

**Deciding factor:** **`another` = one more. `the other` = the last one left. Add `the` when the set
is closed and known.**

## 14. RELATIVE CLAUSES: the comma that changes the meaning

### 14.1 Defining vs non-defining — the decision, not the punctuation

Most books present this as a punctuation rule. It is not. **The comma changes what the sentence is
true of**, which is why `02-what-moves-a-band.md` calls it a "when to use which" point rather than a
punctuation point (§0 item 12), and why Reading test writers exploit it (§6.7).

**Ask yourself:** *Does this clause tell my reader WHICH ONE I mean, or does it just add extra
information about something already identified?*

| Type | Punctuation | Job | Authored example |
|---|---|---|---|
| **Defining (restrictive)** | **No commas** | Identifies which one — remove it and the reader no longer knows who or what you mean | `Students who submitted late were penalised.` |
| **Non-defining (non-restrictive)** | **Commas both sides** (or dashes/brackets) | Adds a comment about something already identified — remove it and the sentence still identifies the same thing | `The final report, which ran to 200 pages, was published in May.` |

**Minimal pair — the one that must be in the chapter:**

> `The engineers who had worked on the bridge were interviewed.`
> → Only *some* of the engineers worked on the bridge. Only those ones were interviewed.
>
> `The engineers, who had worked on the bridge, were interviewed.`
> → **All** of them worked on the bridge, and all of them were interviewed.

Two commas change how many people were interviewed. That is a fact about the world, not a style
preference.

Second pair, for the same reason in a Task-2-shaped sentence:
`Countries that rely on tourism suffered most.` — only those countries.
`Countries, which rely on tourism, suffered most.` — an absurd claim that every country relies on
tourism. **The comma made the sentence false.**

**Deciding factor:** **No commas = it tells you which one. Commas = it is extra information. If you
can delete the clause and still know exactly who or what is meant, use commas.**

### 14.2 The rules that follow automatically from 14.1

| Question | Defining | Non-defining |
|---|---|---|
| Can I use `that`? | Yes | **No** — ✗ `The report, that ran to 200 pages, …` |
| Can I omit the pronoun? | Yes, **if it is the object** of the clause: `the policy (that) the council introduced` | **Never** |
| Which pronouns? | `who, whom, whose, which, that, where, when, why` | `who, whom, whose, which, where, when` |
| Can it refer to a whole clause? | No | **Yes** — `Fees rose in 2011, which coincided with the first fall in applications.` |

### 14.3 `who` vs `which` vs `that` vs `whose` vs `whom`

| Pronoun | Refers to | Authored example | Note |
|---|---|---|---|
| `who` | People | `the researcher who ran the trial` | |
| `which` | Things, animals, and whole clauses | `the trial which ran for two years` | ✗ never for people in careful writing |
| `that` | People or things — **defining clauses only** | `the trial that ran for two years` | |
| `whose` | Possession — **people and things both** | `a company whose margins had collapsed` | Learners think it is people-only; it is not |
| `whom` | People, as an object or after a preposition | `the candidate to whom the offer was made` | Formal and receding |
| `where` | Places | `the region where the scheme began` | |
| `when` | Times | `the year when the levy took effect` | |
| `why` | Reasons | `the reason why it failed` | See the trap below |

**On `which` vs `that` in defining clauses — the honest answer.** Both are standard in British
English and the choice is free. Some American editorial style guides prescribe `that` for defining
clauses and `which` only for non-defining ones. `02-what-moves-a-band.md` §5 item 4 puts this on the
**don't-worry list**: it is not scored. **What is scored is the comma.** Teach the comma; mention the
American convention in one line and move on.

**On `whom`:** grammatically it is the object form. In modern English `who` is acceptable in almost
every position, and using `whom` wrongly is more damaging than not using it. Two safe rules: `whom`
is correct immediately after a preposition (`with whom`, `for whom`); everywhere else, `who` is fine.

**Traps:**
1. **The resumptive pronoun** — the highest-frequency relative-clause error, and it comes from L1
   transfer, because several languages *require* the pronoun English forbids:
   ✗ `The problem which the council is trying to solve it has no cheap answer.` → delete `it`.
   **The relative pronoun IS the object. You do not supply it twice.**
2. ✗ `Students which live far from campus` → `who`.
3. ✗ `The reason why … is because` — doubly redundant. → `The reason … is that`.
4. **Attaching the clause to the wrong noun:** `The report on the schools which was published last
   week` — which was published, the report or the schools? Put the clause next to the noun it
   describes, or restructure.
5. **Opening a non-defining comma and never closing it:** ✗ `Fees rose in 2019, which few families
   had budgeted for cut demand.` Both commas or neither.

**Register:** BOTH. Non-defining `, which …` is Tier A in the risk table — the single best
range-per-risk buy in the language, because it adds a comment without starting a new sentence.

### 14.4 Reduced relative clauses — when you can delete the pronoun and the verb

| Full clause | Reduced | Condition |
|---|---|---|
| `households which are living within walking distance` | `households living within walking distance` | Active meaning → `-ing` |
| `the changes which were introduced in 2019` | `the changes introduced in 2019` | Passive meaning → past participle |
| `the first person who arrived` | `the first person to arrive` | After superlatives, ordinals, `the only`, `the next` |

**Deciding factor:** **Delete `who/which/that + be`. If there is no `be`, change the verb to `-ing`.**
**Trap:** leaving a finite verb behind — ✗ `households live within walking distance of a station
drove more`.

### 14.5 `what` vs `which` vs `that` — the confusion that produces the worst errors

`what` is **not** a relative pronoun in this sense. It means "the thing(s) that".

| Correct | Wrong |
|---|---|
| `Show me the file that you downloaded.` | ✗ `Show me the file what you downloaded.` |
| `Show me what you downloaded.` | — (`what` = "the thing which", with no noun before it) |
| `The scheme was cancelled, which surprised nobody.` | ✗ `…, what surprised nobody.` |

**Deciding factor:** **If there is a noun in front, use `that / which / who`. If there is no noun,
use `what`.**

## 15. VERB PATTERNS: `-ing` vs `to` + infinitive

### 15.0 Honest framing: this is vocabulary, not grammar

There is no rule that predicts whether a verb takes `-ing` or `to`. `enjoy` takes `-ing`; `want`
takes `to`; nothing in their meanings explains it. `02-what-moves-a-band.md` §4.1 classifies this as
**chunk ignorance**, and §9 item 4 recommends it ship as spaced-repetition cards with the whole frame
on the card, not as a grammar lesson.

**A theory chapter's job is therefore different from a practice point's job:** give the learner the
lists, the patterns that DO exist, and — most importantly — the small set of verbs where **the choice
changes the meaning**, because those are real decisions and the rest are just vocabulary.

### 15.1 The patterns that do exist

| Pattern | Members (not exhaustive) | Authored example |
|---|---|---|
| verb + **-ing** | avoid, consider, deny, admit, enjoy, finish, imagine, involve, keep, mind, miss, postpone, practise, risk, suggest, delay, resent | `The report suggests raising the threshold.` |
| verb + **to** | agree, decide, hope, manage, offer, promise, refuse, seem, expect, plan, afford, pretend, threaten, fail, tend, learn, choose | `They agreed to review the policy.` |
| verb + **object + to** | allow, enable, encourage, force, persuade, advise, remind, warn, invite, expect, want, teach | `The reform enabled councils to borrow directly.` |
| verb + **object + bare infinitive** | make, let, have (causative); also `help` (with or without `to`) | `The rules make employers report the data.` |
| **preposition + -ing** — always | in, on, at, of, about, for, without, after, before, by, instead of, despite, look forward to, be used to | `They succeeded in cutting waiting times.` |
| adjective + **to** | difficult, easy, important, likely, able, willing, ready, reluctant | `It is difficult to argue that the policy failed.` |
| noun + **to** | ability, decision, attempt, opportunity, failure, tendency, willingness | `their failure to publish the data` |
| **-ing as a subject** | any verb | `Cutting fares would not by itself reduce congestion.` |

**The one reliable structural rule worth teaching:** **after a preposition, a verb is always `-ing`.**
Because `to` is sometimes a preposition (`look forward to`, `be used to`, `object to`, `be committed
to`), this produces the sentences learners are sure are wrong: `I look forward to hearing from you.`
✓ ✗ `to hear`. Name it, or the learner will "correct" the right form.

### 15.2 The verbs where the choice CHANGES THE MEANING — this is the real decision

These are the only ones that belong in a "when to use which" chapter. Every one of them is a genuine
minimal pair.

| Verb | + `to` | + `-ing` |
|---|---|---|
| **remember** | Remember, then do it (the memory comes first) — `Remember to lock the door.` | Do it, then have the memory — `I remember locking the door.` |
| **forget** | Fail to do it — `I forgot to send the file.` | Have no memory of doing it — `I'll never forget seeing it.` |
| **stop** | Stop **in order to** do something else — `We stopped to check the map.` | Cease the activity — `We stopped checking the map.` |
| **try** | Attempt something difficult — `I tried to open the file.` (it may have failed) | Experiment, to see what happens — `Try opening it in another program.` |
| **regret** | About to give bad news (formal) — `We regret to inform you…` | Be sorry about a past action — `I regret sending that email.` |
| **go on** | Move to the next thing — `She went on to describe the method.` | Continue the same thing — `She went on describing the method.` |
| **mean** | Intend — `I meant to call you.` | Involve, entail — `Expanding the site would mean rehousing 200 families.` |
| **need** | Someone needs to act — `You need to renew it.` | It requires action (passive meaning; chiefly British) — `The roof needs repairing.` |
| **like / love / hate** | A choice, or one specific occasion — `I'd like to see the figures.` | Enjoy or dislike the activity itself — `I like walking to work.` (in BrE the two are often interchangeable; `would like to` is always the specific-occasion form) |
| **help** | `The grant helped to reduce waiting times.` | — (`help` uniquely takes the bare infinitive too: `helped reduce`. **All three are correct.**) |

**Minimal pair to lead with, because it is the clearest:**
`He stopped to smoke.` — he stopped what he was doing so that he could smoke.
`He stopped smoking.` — he gave up cigarettes.
**Same three words, opposite biographies.**

**Deciding factor:** **`to` + infinitive usually points FORWARD to a purpose or an intention.
`-ing` usually points at the activity itself, or BACK at something that already happened.** That
tendency is real and worth stating — but say honestly that it is a pattern, not a law, and that the
rest of the verbs simply have to be learned as items.

### 15.3 The verb patterns learners get wrong most often

| ✗ Wrong | ✓ Right | Why |
|---|---|---|
| `I suggest to build more housing.` | `I suggest building more housing.` / `I suggest that the council build more housing.` | `suggest` never takes `verb + to` and never takes an object + to |
| `They allowed that people rent it.` | `They allowed people to rent it.` | `allow` + object + to |
| `The rules make employers to report.` | `The rules make employers report.` | `make` and `let` take the bare infinitive |
| `I look forward to hear from you.` | `I look forward to hearing from you.` | `to` here is a preposition |
| `She is interested to learn languages.` | `She is interested in learning languages.` | preposition + `-ing` |
| `He avoided to answer.` | `He avoided answering.` | `avoid` + `-ing` |
| `I recommend you to read it.` | `I recommend reading it.` / `I recommend that you read it.` | like `suggest` |
| `We discussed about the cost.` | `We discussed the cost.` | `discuss` takes a direct object, no preposition |

### 15.4 `see`/`hear` + object + `-ing` vs bare infinitive

**Ask yourself:** *Did I perceive the whole action, or just part of it in progress?*

`I saw her leave the building.` — I saw the complete event.
`I saw her leaving the building.` — I saw it in progress; I may not have seen the end.

**Deciding factor:** **Bare infinitive = the whole action. `-ing` = the action in progress.**

### 15.5 The causatives: `make` / `let` / `have` / `get`

| Form | Meaning | Authored example |
|---|---|---|
| `make somebody do` | Force | `The audit made the department publish its costs.` |
| `let somebody do` | Allow (informal) | `They let us keep the equipment.` |
| `have something done` | Arrange for a service | `We had the roof repaired.` |
| `get somebody to do` | Persuade | `I finally got them to reply.` |
| `get something done` | Arrange for a service (more informal than `have`) | `I need to get the report checked.` |

**Minimal pair:** `I repaired the roof.` (I did it myself) vs `I had the roof repaired.` (I paid
someone). This distinction is invisible to many learners and produces unintentionally heroic
sentences.

**Register:** `let` and `get` are informal — in Task 2 prefer `allow … to` and `persuade … to`.

## 16. TIME WORDS: the prepositions and conjunctions learners swap

### 16.1 `since` vs `for`

**Ask yourself:** *Am I naming the START POINT, or the LENGTH?*

| Form | Takes | Authored example |
|---|---|---|
| **since** | A point in time — a date, an event, a clock time | `They have run the scheme since 2011.` `since I moved here` |
| **for** | A length of time | `They have run the scheme for fourteen years.` `for six months` |

**Minimal pair:** `since March` (from March up to now) vs `for March` ✗ (meaningless) — and
`for three years` vs `since three years` ✗, which is the actual error, imported from languages where
one word covers both.

**Deciding factor:** **`since` answers "starting when?". `for` answers "how long?".**

**Traps and extensions:**
- `since` almost always pulls a **perfect** tense (§2.1). `for` can go with any tense: `I worked
  there for two years` (finished) vs `I have worked there for two years` (still there).
- **`since` also means "because"** — `Since the data was incomplete, the study was repeated.` This is
  a genuine second meaning and it is formal-neutral; learners meet it in Reading and are confused.
  Use `as` or `since` for a reason the reader already knows, `because` for the new, important reason.
- `ago` counts back from now and takes the **past simple**: `three years ago` ✓, ✗ `since three years
  ago I have…`.
- `from … to / until` sets both ends: `from 2011 to 2019`.

### 16.2 `during` vs `while` vs `for` vs `in`

**Ask yourself:** *Is the next word a NOUN or a CLAUSE?*

| Form | Followed by | Authored example |
|---|---|---|
| **during** | A noun (a named period or event) — answers *when* | `Attendance fell during the pandemic.` |
| **while** | A **clause** (subject + verb) — two things at the same time | `Attendance fell while the restrictions were in place.` |
| **for** | A length — answers *how long* | `Attendance fell for eighteen months.` |
| **in** | A period, often the time taken to complete something | `The backlog was cleared in six weeks.` |
| **meanwhile** | An adverb joining two sentences | `Costs rose. Meanwhile, funding was frozen.` |

**Minimal pairs:**
`It rained during the match.` (at some point, or throughout) vs `It rained for the match` ✗.
`I read during the flight.` vs `I read while I was flying.` — same meaning, different grammar after
the word.
`He wrote it in two hours.` (that is how long it took to finish) vs `He wrote for two hours.` (that
is how long he spent; it may be unfinished).

**Deciding factor:** **`during` + noun. `while` + clause. `for` + a length. `in` + the time it took to
finish.**

**Trap:** ✗ `during I was studying` → `while I was studying`. This is one of the highest-frequency
single-word errors in learner writing.

**Honest note:** `while` also has a **contrast** meaning with no time in it at all — `While the cost
is high, the benefit is clear.` (= although). That double duty is real and it is worth flagging in
both this section and §17, because a learner meeting `while` in a Reading passage has to work out
which one it is. `whereas` never means time, which is precisely why it is the safer contrast word.

### 16.3 `by` vs `until` vs `by the time`

**Ask yourself:** *Does the situation CONTINUE up to that point, or does it just have to HAPPEN
before it?*

| Form | Meaning | Authored example |
|---|---|---|
| **by** | Not later than; at some point before the deadline | `Submit the form by Friday.` (any time before Friday) |
| **until / till** | Continuously up to that point, then it stops | `The office is open until Friday.` (and closes after) |
| **by the time** + clause | At the moment when that happened / happens | `By the time the funding arrived, most of the staff had left.` |

**Minimal pair:** `I'll be there by six.` (I will arrive at some point before six) vs `I'll be there
until six.` (I am there now or from earlier, and I leave at six). **Opposite arrangements.**

**Deciding factor:** **`by` = a deadline. `until` = a duration that ends.**

**Trap:** `until` with a negative sentence is fine and very common: `The results were not published
until March.`

### 16.4 `in` / `on` / `at` for time and place

The smallest and highest-frequency preposition decision. A reference book needs the table.

| | `at` | `on` | `in` |
|---|---|---|---|
| **Time** | clock times, `at night`, `at the weekend` (BrE), festivals: `at 9.15`, `at Easter` | days and dates: `on Monday`, `on 4 June`, `on the weekend` (AmE) | months, seasons, years, centuries, parts of the day: `in July`, `in 2019`, `in the morning` |
| **Place** | a point or a specific spot: `at the entrance`, `at the station`, `at work` | a surface or a line: `on the shelf`, `on the coast`, `on the third floor` | an enclosed space or an area: `in the building`, `in Berlin`, `in the north` |

**Deciding factor:** **Smallest and most precise → `at`. A surface or a day → `on`. Inside something,
or a longer period → `in`.**

**Register/variation note:** `at the weekend` is British, `on the weekend` is American, both are
standard. `in the street` is British, `on the street` is American.

**Honest note about prepositions generally:** most preposition errors are **not** rule errors. They
are **dependent prepositions** — the preposition is stored with the word it attaches to (`a solution
**to**`, `an impact **on**`, `depend **on**`, `an increase **in**`, `interested **in**`, `responsible
**for**`, `discuss ∅`). `02-what-moves-a-band.md` §4 item 5 and §9 item 4 both say these are
vocabulary items and belong on cards with the whole chunk. **A theory chapter should say so and give
a reference list, not pretend there is a system.**

## 17. CONTRAST AND CONCESSION: `although` vs `despite` vs `however` vs `whereas` vs `but`

### 17.0 The decision is grammatical, not stylistic

Learners are taught these as a list of "linking words" and swap them freely, which produces the
single most common connector error in the language: ✗ `Despite the cost was high…`. The choice is
determined by **what kind of thing comes next**, and that makes it a grammar decision.

**Ask yourself:** *What comes after this word — a full clause, a noun, or a new sentence?*

| Word | What follows it | Authored example |
|---|---|---|
| **although / though / even though** | A **clause** (subject + verb) | `Although the cost was high, the scheme went ahead.` |
| **despite / in spite of** | A **noun** or an **`-ing` form** (never a clause) | `Despite the high cost, the scheme went ahead.` / `Despite being expensive, …` |
| **despite the fact that** | A clause (the escape hatch) | `Despite the fact that the cost was high, …` |
| **however / nevertheless / nonetheless** | A **new sentence** (or after a semicolon), with a comma | `The cost was high. However, the scheme went ahead.` |
| **but / yet** | Joins two clauses inside one sentence, with a comma before it | `The cost was high, but the scheme went ahead.` |
| **whereas / while** | Joins two clauses that **contrast** — two different things, not a concession | `Older workers value security, whereas younger ones rank flexibility first.` |

### 17.1 Concession vs contrast — the distinction underneath the word list

This is the part that is almost never taught and it is what makes the choice meaningful:

- **Concession** (`although`, `despite`, `even though`, `however`) = *this fact is true and it argues
  against my point, but my point stands anyway.* There is tension between the two halves.
- **Contrast** (`whereas`, `while`, `by contrast`, `on the other hand`) = *these two things are
  simply different.* No tension, no surrender of anything.

**Minimal pair:**
`Although rural clinics lost staff, urban ones grew.` — presented as surprising; the two facts are in
tension.
`Rural clinics lost staff, whereas urban ones grew.` — presented as a straight comparison.
Both are correct; they position the writer differently, and the second is what an Academic Task 1
comparison actually needs.

**Deciding factor:** **`although` + clause. `despite` + noun/`-ing`. `however` + new sentence.
`whereas` = two things are different; `although` = one fact does not defeat the other.**

### 17.2 The traps, all four of them

1. ✗ **`Despite the cost was high`** — the highest-frequency connector error there is. `despite` is a
   preposition, so a clause cannot follow it. Three legal repairs: `Despite the high cost`,
   `Despite being expensive`, `Although the cost was high`.
2. ✗ **`Although it is expensive, but it works.`** — the double connector. English uses **one**
   connector per relationship. Keep `although` or keep `but`, never both. (This is an L1-transfer
   error: several languages require the pair.)
3. ✗ **`However the cost was high, the scheme went ahead.`** — `however` is an adverb, not a
   conjunction. It cannot join two clauses. → `The cost was high. However, the scheme went ahead.`
   or `…was high; however, the scheme went ahead.`
   (`however` does have a separate meaning — "in whatever way": `However you look at it, the numbers
   are poor.` Flag this so learners are not confused when they meet it.)
4. **`whereas` used for time.** It never means time. `While` does both; `whereas` does not.

**Register:** `although`, `however`, `whereas`, `despite` — BOTH, and Tier A in the risk table (a
fronted `While …, …` concession is the sentence that most reliably reads as band 7, because it does
a grammar job and a Task Response job at once). `though` at the **end** of a sentence (`It's
expensive, though.`) is SPOKEN-only and should never appear in an essay. `nevertheless` and
`nonetheless` are formal WRITTEN.

### 17.3 The neighbouring connector families, for completeness

| Relationship | Inside one sentence | Between sentences | Preposition + noun |
|---|---|---|---|
| Addition | `and`, `not only … but also` | `Moreover`, `In addition`, `Furthermore` | `in addition to`, `besides` |
| Cause | `because`, `since`, `as` | `Therefore`, `Consequently`, `As a result` | `because of`, `due to`, `owing to` |
| Result | `so`, `so that` | `Therefore`, `Thus`, `Hence` | — |
| Purpose | `so that`, `in order that` | — | `in order to`, `so as to`, `to` |
| Contrast | `but`, `whereas`, `while`, `yet` | `However`, `By contrast`, `On the other hand` | `unlike`, `despite`, `in spite of` |
| Condition | `if`, `unless`, `provided that` | `Otherwise` | `in the event of` |
| Example | — | `For example`, `For instance` | `such as`, `like` |

**Two decisions inside that table worth their own boxes:**

**`because` vs `because of` vs `due to`.** `because` + clause (`because prices rose`); `because of` +
noun (`because of the price rise`). `due to` + noun as well, and it is more formal. A traditional
prescriptive rule says `due to` should only follow a form of `be` (`The delay was due to flooding`)
and that `owing to` or `because of` should be used adverbially (`The flight was cancelled owing to
flooding`). That distinction is widely ignored in modern usage and is not worth a learner's time —
but say that it exists, so a learner corrected by an old-fashioned teacher knows what happened.

**`so` vs `so that`.** `so` = result (`It rained, so we cancelled`). `so that` = purpose (`We
rescheduled so that everyone could attend`). The result `so` is slightly informal in academic writing;
prefer `therefore`, `consequently`, `as a result`.

## 18. DEGREE: `so` vs `such`, `too` vs `enough` vs `very`

### 18.1 `so` vs `such`

**Ask yourself:** *Is there a NOUN in the phrase I am intensifying?*

| Form | Structure | Authored example |
|---|---|---|
| **so** | `so` + adjective / adverb (no noun) | `The fee was so high that enrolment collapsed.` |
| **so** | `so much / so many / so little / so few` + noun | `There were so many applicants that the site crashed.` |
| **such** | `such (a/an) (+ adjective) + noun` | `It was such a high fee that enrolment collapsed.` |

**Minimal pair (the meaning is identical; only the grammar differs):**
`The delay was so long that we left.` ✓
`It was such a long delay that we left.` ✓
✗ `It was so long delay…` ✗ `The delay was such long…`

**Deciding factor:** **Noun in the phrase → `such`. No noun → `so`. The exception is amounts, where
it is `so much` / `so many`.**

**Trap:** `such a` only works with a **singular countable** noun. With plurals and uncountables, drop
the `a`: `such high fees`, `such poor weather`.

### 18.2 `too` vs `enough` vs `very`

**Ask yourself:** *Is this a problem, or just a description?*

| Form | Meaning | Position | Authored example |
|---|---|---|---|
| **too** | More than is acceptable — **always negative** | before the adjective/adverb | `The flat was too small for four people.` |
| **enough** | The necessary amount — neutral or positive | **after** an adjective/adverb, **before** a noun | `The flat was big enough.` / `There wasn't enough space.` |
| **very** | A high degree — neutral, no judgement | before the adjective/adverb | `The flat was very small.` |

**Minimal pair — this pair is worth a whole box because the error is so common:**
`The course was very difficult.` — hard, but I did it.
`The course was too difficult.` — so hard that I could not do it. **`too` always implies failure or a
problem.**
And: `He is old enough to vote.` (he can) vs `He is too old to qualify.` (he can't).

**Deciding factor:** **`too` = a problem. `enough` = sufficient. `very` = just intensity. `too` is
never a compliment.**

**Traps:**
- ✗ `too much good`, ✗ `too very` — `too` and `very` do not stack.
- Word order: ✗ `enough big` → `big enough`; but ✓ `enough time` (before a noun).
- `too much` + uncountable, `too many` + countable.
- `not enough` is the negative of `enough`, and it does the job that learners try to give `too little`.

### 18.3 `also` / `too` / `as well` / `either`

| Form | Position | Sentence type | Authored example |
|---|---|---|---|
| `also` | Mid-sentence, before the main verb / after `be` | positive | `The scheme also reduced emissions.` |
| `too` | End of the clause | positive | `The scheme reduced emissions too.` |
| `as well` | End of the clause; slightly informal | positive | `It cut costs as well.` |
| `either` | End of the clause | **negative** | `It didn't cut costs either.` |

**Deciding factor:** **In a negative sentence, "also" is `either`.** ✗ `It didn't work too.`

## 19. COMPARISON: which comparative form

### 19.1 `-er` vs `more`

| Adjective type | Form | Examples |
|---|---|---|
| One syllable | `-er / -est` | `cheap → cheaper → the cheapest` |
| Two syllables ending `-y` | `-ier / -iest` | `easy → easier` |
| Most other two-syllable | Usually `more` (both often possible) | `more common` / `commoner` — both standard |
| Three or more syllables | `more / most` | `more expensive` |
| Irregular | — | `good → better → best`, `bad → worse → worst`, `far → further/farther` |

**Honest note:** the two-syllable group genuinely varies (`politer` and `more polite` are both fine).
Do not present a false certainty; tell the learner that `more` is always safe there.

### 19.2 The comparison structures, and the errors in each

| Structure | Use | Authored example | Trap |
|---|---|---|---|
| `-er / more … than` | Two things compared | `Rents rose faster in coastal towns than inland.` | ✗ **double comparative** `more higher`, `more cheaper` |
| `the -est / the most` | Three or more | `the highest figure in the series` | ✗ dropping `the` |
| `as … as` | Equality | `Costs were as high as they had been in 2008.` | ✗ `as high than` |
| `not as … as` | Inequality | `Rural take-up was not as strong as urban.` | ✗ `not so … than` |
| `twice / three times as … as` | Multiples | `Applications were twice as high as in 2015.` | ✗ `twice more than` |
| `much / far / a lot / slightly + comparative` | Degree of difference | `far higher`, `slightly lower` | ✗ **`very higher`** — `very` cannot modify a comparative |
| `the … the …` | Parallel change | `The longer the delay, the greater the cost.` | word order |
| `by` + amount | Size of a change | `Output rose by 12%` | ✗ confusing with `to` |
| `to` + level | The level reached | `Output rose to 340 tonnes` | the `by`/`to` swap is near-universal in Task 1 |

**Minimal pair worth teaching in Task 1:** `Output rose by 12%.` (that is the size of the increase)
vs `Output rose to 12%.` (that is the level it reached). **Different numbers entirely.**

**Deciding factor:** **One comparative marker only, ever. `by` = the size of the change; `to` = the
level reached.**

### 19.3 `like` vs `as` vs `such as`

| Form | Use | Authored example |
|---|---|---|
| `like` + noun | Similar to | `Cities like Lagos face the same pressure.` |
| `as` + clause | In the way that | `As the chart shows, the trend reversed after 2015.` |
| `as` + noun | In the role of | `She worked as a translator.` |
| `such as` | For example (formal) | `Heavy industries such as steel and cement` |

**Minimal pair:** `He worked like a consultant.` (he behaved that way — he wasn't one) vs `He worked
as a consultant.` (that was his job). **A real difference in what happened.**

**Trap:** ✗ `As I said before, like the chart shows…` — `like` + clause (`like the chart shows`) is
extremely common in informal speech and is disliked in formal writing. Use `as` in Task 2.

## 20. QUESTIONS AND REPORTED SPEECH

### 20.1 WH questions: subject questions vs object questions

The user named "WH questions" explicitly, and this is the decision inside them that nobody teaches.

**Ask yourself:** *Is the WH-word the SUBJECT of the question, or the object?*

| Type | Structure | Authored example |
|---|---|---|
| **Subject question** — the WH-word is who/what is doing it | **No auxiliary, no `do`.** Statement word order | `Who wrote the report?` `What caused the delay?` |
| **Object question** — the WH-word is what is affected | Auxiliary + subject + verb | `Who did you ask?` `What did the council decide?` |

**Minimal pair:**
`Who called Ana?` — I want to know the caller. (Subject question — no `did`.)
`Who did Ana call?` — I want to know who received the call. (Object question — `did` required.)
✗ `Who did call Ana?` (unless you are being emphatic, which is a different structure entirely.)

**Deciding factor:** **If the answer to the question would be the subject of the sentence, do not use
`do/does/did`.**

### 20.2 The WH-words, and the ones that are confused

| Word | Asks about | Authored example | Confusion |
|---|---|---|---|
| `who` | People (subject) | `Who signed it?` | vs `whom` (object, formal) |
| `whose` | Possession | `Whose signature is this?` | vs `who's` = *who is* |
| `which` | A choice from a known set | `Which of the two sites was chosen?` | vs `what`, below |
| `what` | An open set | `What did they decide?` | |
| `when / where / why / how` | Time, place, reason, manner | `How was the figure calculated?` | |
| `how much / how many / how long / how often` | Amounts and frequency | `How long has it been running?` | `how long` (duration) vs `how far` (distance) |

**`which` vs `what`:** `Which colour do you want?` implies a limited set in front of us. `What colour
do you want?` leaves it open. **Deciding factor: closed set → `which`; open set → `what`.**

### 20.3 Direct vs indirect (embedded) questions

**Ask yourself:** *Is this a question on its own, or a question inside another sentence?*

| Type | Word order | Authored example |
|---|---|---|
| **Direct question** | Inverted: auxiliary before the subject | `Where is the deposit held?` |
| **Indirect / embedded** | **Statement order**, no `do/does/did` | `I would like to know where the deposit is held.` |

**Minimal pair:**
`Why did the scheme fail?` ✓ (direct)
`Nobody knows why the scheme failed.` ✓ (embedded — statement order)
✗ `Nobody knows why did the scheme fail.` — a classic over-generalisation error, listed at #11 in
`02-what-moves-a-band.md` §4, and one that can turn **global**.

**Deciding factor:** **After `know / wonder / ask / tell me / could you tell me / I'd like to know`,
the question stops being a question and takes statement order.**

**Also:** yes/no questions embed with `if` or `whether`: `I'd like to know whether the deposit is
refundable.` ✗ `…know is the deposit refundable.` Use `whether` (not `if`) before `to` + verb and
after a preposition.

**Register:** indirect questions are the polite register of a GT formal letter and of Speaking when
you ask the examiner for clarification. `Could you tell me…` outranks `Tell me…` by a long way.

### 20.4 Question tags — the choice, in one line each

| Statement | Tag | Rule |
|---|---|---|
| `The results are out,` | `aren't they?` | Positive statement → negative tag |
| `The results aren't out,` | `are they?` | Negative statement → positive tag |
| `You've seen it,` | `haven't you?` | Repeat the auxiliary |
| `She left early,` | `didn't she?` | No auxiliary → use `do/does/did` |
| `Let's start,` | `shall we?` | Fixed |
| `Open the window,` | `will you?` | Imperative |

**Register:** SPOKEN. Tags belong in Speaking and in informal letters; they have no place in Task 2.
Their intonation carries meaning (falling = seeking agreement, rising = a genuine question), which is
a pronunciation point, not a grammar one.

### 20.5 Reported speech: `say` vs `tell`, and whether to backshift

**`say` vs `tell`:**

| Verb | Structure | Authored example |
|---|---|---|
| `say` | `say (that) …` — **no person object** unless you add `to` | `She said that the deadline had moved.` / `She said to me…` |
| `tell` | `tell somebody (that) …` — **always a person object** | `She told the team that the deadline had moved.` |

✗ `She said me…` ✗ `She told that…` — both are extremely common and both are errors.
Related: `speak to somebody`, `talk to somebody about something`, `discuss something` (no
preposition), `explain something to somebody` (✗ `explain me`).

**Backshift — the actual decision:**

**Ask yourself:** *Is what was said still true now?*

| Situation | What to do | Authored example |
|---|---|---|
| The reporting verb is past and the statement is finished or no longer relevant | Shift the tense back one step: present → past, past → past perfect, `will` → `would`, `can` → `could`, `must` → `had to` | `"We are reviewing it."` → `She said they were reviewing it.` |
| The statement is still true, or a general fact | **Backshift is optional** — leaving the present tense is correct and often more natural | `He said the office closes at five.` ✓ (it still does) |
| The reporting verb is present (`says`, `argues`, `claims`) | **No backshift** | `The report argues that funding is insufficient.` |

**Minimal pair:** `She said she was a vegetarian.` (neutral — or possibly no longer) vs `She said she
is a vegetarian.` (still is, and I am confirming it).

**Deciding factor:** **Backshift when the statement belongs to the past. Keep the tense when it is
still true.** Reporting is not a mechanical transformation, and teaching it as one is why learners
produce absurd sentences about permanent facts.

**Other shifts:** pronouns and time/place words move too — `here → there`, `now → then`, `today →
that day`, `tomorrow → the next day`, `this → that`. But only shift what the change of viewpoint
actually requires.

**Reporting verbs carry meaning — this is the range payoff.** `said` is the neutral one; choosing a
more specific verb is both accurate and a Lexical Resource gain: `argued that`, `claimed that`,
`admitted that`, `denied -ing`, `suggested -ing`, `warned that`, `pointed out that`, `insisted on
-ing`, `refused to`, `promised to`, `agreed to`, `advised somebody to`. Note the patterns differ, so
each is a chunk (§15).

**Register:** WRITTEN, heavily — Task 2 uses reporting structures to present other people's views
before disagreeing with them, and Reading passages are full of them.

## 21. ADVERBS, ADJECTIVES, AND THE CONFUSION PAIRS

### 21.1 Adjective or adverb?

**Ask yourself:** *Am I describing a NOUN, or a VERB?*

| Form | Describes | Authored example |
|---|---|---|
| Adjective | A noun | `a sharp fall` |
| Adverb | A verb, an adjective, or another adverb | `fell sharply` |

**Trap:** after `be, seem, look, feel, taste, smell, sound, become` — the "linking verbs" — English
uses an **adjective**, not an adverb, because the word describes the subject:
`It seems reasonable.` ✓ ✗ `It seems reasonably.`
`The proposal sounds sensible.` ✓

### 21.2 The `-ly` pairs where both forms exist and mean different things

This is a genuine minimal-pair set and a favourite of test writers.

| Pair | Meaning A | Meaning B |
|---|---|---|
| `hard` / `hardly` | `She works hard.` = a lot | `She hardly works.` = almost not at all |
| `late` / `lately` | `He arrived late.` = not on time | `He hasn't been well lately.` = recently |
| `near` / `nearly` | `They live near the coast.` = close to | `It nearly collapsed.` = almost |
| `high` / `highly` | `The bird flew high.` = physical height | `a highly regarded study` = very |
| `free` / `freely` | `Children travel free.` = at no cost | `They spoke freely.` = without restriction |
| `most` / `mostly` | `the most common cause` = superlative | `The delays were mostly administrative.` = mainly |
| `wide` / `widely` | `Open it wide.` | `a widely held view` = by many people |

**Deciding factor:** **These are not the same word with a suffix — they are different words. Learn
them as pairs, in sentences.** `hardly` is the dangerous one: it is a **negative** word, so
`I can hardly hear you` needs no `not`, and ✗ `I can't hardly hear you` is a double negative.

### 21.3 `still` vs `yet` vs `already`

| Form | Meaning | Position | Authored example |
|---|---|---|---|
| `still` | Continuing, unchanged — often longer than expected | mid-sentence | `The application is still under review.` |
| `yet` | Up to now (in negatives and questions) | end of the clause | `The results haven't arrived yet.` `Have they arrived yet?` |
| `already` | Earlier than expected | mid-sentence, or end for emphasis | `Two of the sites have already closed.` |

**Minimal pair:** `She hasn't replied yet.` (I expect a reply) vs `She still hasn't replied.` (and I
am now annoyed). **`still` + negative adds impatience.**

**Deciding factor:** **`still` = it continues. `yet` = not up to now. `already` = sooner than
expected.**

### 21.4 The other high-frequency confusion pairs

Not all of these are grammar in the strict sense — some are vocabulary — but learners bring them to a
grammar reference, so a reference book should answer them.

| Pair | The distinction | Authored examples |
|---|---|---|
| `between` / `among` | `between` for two, or for individually-considered items; `among` for an undifferentiated group | `between the two options` · `a decision between three suppliers` (individual) · `common among students` |
| `beside` / `besides` | `beside` = next to; `besides` = in addition to | `beside the river` · `Besides the cost, there is the delay.` |
| `its` / `it's` | `its` = belonging to it; `it's` = *it is* / *it has* | `The scheme lost its funding.` · `It's been cancelled.` |
| `whose` / `who's` | `whose` = belonging to whom; `who's` = *who is* | `the firm whose bid won` · `Who's responsible?` |
| `there` / `their` / `they're` | place · possession · *they are* | — |
| `affect` / `effect` | `affect` = verb, to influence; `effect` = noun, a result (`effect` is also a rare formal verb meaning "bring about") | `The levy affected demand.` · `The effect was immediate.` |
| `rise` / `raise` | `rise` is intransitive (no object); `raise` takes an object | `Prices rose.` · `The council raised fares.` |
| `lie` / `lay` | `lie` = be in a position (no object); `lay` = put something down (object) | `The report lay unread.` · `They laid the foundations.` |
| `borrow` / `lend` | `borrow` = take; `lend` = give | `I borrowed it from her.` · `She lent it to me.` |
| `bring` / `take` | `bring` = towards the speaker; `take` = away | — |
| `economic` / `economical` | `economic` = about the economy; `economical` = cheap to run | `economic growth` · `an economical car` |
| `historic` / `historical` | `historic` = important in history; `historical` = relating to the past | `a historic decision` · `historical records` |
| `sensitive` / `sensible` | `sensitive` = easily affected; `sensible` = showing good judgement | — |
| `travel / trip / journey` | `travel` is usually uncountable; a `trip` is a there-and-back with a purpose; a `journey` is the act of going | `Travel broadens the mind.` · `a business trip` · `a two-hour journey` |
| `do` / `make` | Broadly: `do` an activity or a job, `make` a thing or a decision — but the boundary is collocational, not logical | `do research`, `do homework` · `make a decision`, `make progress` |

**Honest note:** the last row is the honest one. `do` vs `make` has no rule; it is collocation, and
learners must store the chunks. Do not invent a rule for it.

### 21.5 Adverb placement — where the word goes

**Ask yourself:** *What kind of adverb is it?*

| Type | Normal position | Authored example |
|---|---|---|
| Frequency (`always, usually, often, rarely, never`) | Before the main verb; **after** `be`; between auxiliary and main verb | `I usually cycle in.` `She is always late.` `They have never replied.` |
| Manner (`carefully, sharply`) | Usually after the verb or the object | `Enrolment fell sharply.` |
| Time (`yesterday, in 2019`) | Start or end of the clause | `In 2019, the levy took effect.` |
| Comment (`fortunately, arguably, admittedly`) | Start of the sentence, with a comma | `Arguably, the scheme was mistimed.` |
| Degree (`very, quite, extremely`) | Immediately before the word they modify | `an extremely narrow margin` |

**Trap:** ✗ `I know always the answer.` → `I always know the answer.` **An adverb almost never goes
between a verb and its object in English.** This is a genuinely different rule from many languages
and it is worth stating as a prohibition, because that is the shape the error takes.

**Bonus payoff:** starting a sentence with a comment adverb or a time phrase is one of the cheapest
ways to vary sentence openings — the most countable proxy for "range" there is
(`02-what-moves-a-band.md` §7 item 8).

### 21.6 Adjective order before a noun

When several adjectives stack, English has a strong preferred order. Native speakers follow it
without knowing it exists, and a learner who breaks it sounds odd without anyone being able to say
why.

**opinion → size → age → shape → colour → origin → material → purpose → NOUN**

`a striking large modern glass office block`

**Honest note:** this is a strong tendency, not an absolute law, and speakers depart from it for
emphasis. Also: **two or three adjectives before a noun is plenty.** Piling up five is a stylistic
problem, not a grammar achievement.

## 22. PUNCTUATION AS A CHOICE

Punctuation is scored inside GRA in Writing and has no equivalent in Speaking
(`02-what-moves-a-band.md` §2.3 item 1), and sentence-boundary control is the **single highest-value
item in the entire module** (§0 item 1). A theory reference should therefore present the marks as a
**choice between legal options**, not as a list of rules.

### 22.1 Joining two complete ideas — four legal options

**Ask yourself:** *Could each half stand alone as a sentence?* If yes, a comma **on its own** is not
one of your options.

| Option | Form | Authored example | Feel |
|---|---|---|---|
| Full stop | `A. B.` | `Cities are growing fast. This puts pressure on housing.` | Neutral; always safe |
| Comma + coordinator | `A, and/but/so B.` | `Cities are growing fast, and this puts pressure on housing.` | Neutral, connected |
| Semicolon | `A; B.` | `Cities are growing fast; this puts pressure on housing.` | Formal; signals a tight link |
| Subordination | `As A, B.` | `As cities grow, pressure on housing increases.` | The most sophisticated, and it earns range credit |

✗ **Comma splice:** `Cities are growing fast, this puts pressure on housing.` This is the error, and
it is common because in several languages a comma legitimately joins clauses.

**Deciding factor:** **If both sides could be sentences on their own, a comma alone is not enough.**

### 22.2 The other marks, as decisions

| Mark | Use it when | Authored example |
|---|---|---|
| **Colon** `:` | The second part explains, expands or lists what the first part announced | `The cause was simple: nobody had checked the figures.` |
| **Semicolon** `;` | Two closely linked complete ideas; also to separate list items that already contain commas | `Rural take-up was strong; urban take-up was not.` |
| **Dash** `—` | An abrupt aside or an emphatic addition. Informal-ish; one per essay at most | `The result was predictable — and predicted.` |
| **Comma pair** `, … ,` | Around non-essential information (§14) | `The final report, which ran to 200 pages, was published in May.` |
| **Apostrophe** `'` | Possession (`the council's decision`) and contraction (`it's` = it is) — **never a plural** | ✗ `Many student's struggle` |

**The apostrophe three-way sort** is worth a drill of its own: plural `-s` (no apostrophe) /
possessive `-'s` / contraction `-'s`. Speech does not distinguish them, which is why the error
survives.

**Fragments:** a subordinate clause punctuated as a sentence is a fragment: ✗ `Because more people
work from home. Traffic has fallen.` → `Because more people work from home, traffic has fallen.`
Note that **`Because` at the start of a sentence is perfectly correct** as long as the main clause
follows. Teaching "never start with Because" is what *produces* this error.

## 23. WORD ORDER AND SENTENCE-LEVEL CHOICES

| Decision | Options | Authored example | When |
|---|---|---|---|
| Where to put the subordinate clause | Front or back | `Although costs rose, demand held up.` / `Demand held up, although costs rose.` | Fronting emphasises the concession and varies the sentence opening — a cheap range gain |
| `There is/are` vs a plain subject | `There are three reasons…` vs `Three reasons explain…` | — | `there is` introduces something new; a plain subject is stronger and more concise. Do not open every paragraph with `There are many…` |
| `It is + adjective + to` (extraposition) | `It is difficult to argue that…` | — | Safe, useful, Tier B. Trap: dropping the `it` |
| Cleft for emphasis | `What the figures show is a slow recovery.` | — | **Once per essay maximum.** More is a tic, and clefts make your own opinion sound like someone else's report |
| Fronted adverbial | `In most developed economies, the trend reversed after 2015.` | — | The cheapest way to vary a sentence opening |
| Negative inversion | `Not only does the levy raise revenue, it also…` | — | **Tier C — avoid.** Error surface 4. Use `not only … but also` without inversion |
| Nominalisation | `the introduction of the charge` vs `the charge was introduced` | — | One nominalised subject per paragraph, then verbs |

## 24. NON-DECISIONS: things learners agonise over that do not matter

Deleting a worry is as valuable as adding a rule. This list is the theory-section counterpart of
`02-what-moves-a-band.md` §5 and must stay consistent with it.

| The worry | The truth |
|---|---|
| `which` vs `that` in defining clauses | Both standard in British English. **The comma is what matters**, not the pronoun |
| The Oxford/serial comma | Optional. Never scored either way |
| British vs American spelling | Both accepted. Consistency reads better; mixing is not a published penalty |
| "Never split an infinitive" | Not a rule of English. `to clearly state` is fine |
| "Never end a sentence with a preposition" | Not a rule of English. Rewriting to avoid it often produces worse sentences |
| "Never start a sentence with `And` / `But` / `Because`" | Not a rule. With `Because`, the **fragment** is the error, not the word |
| `whom` | Optional almost everywhere. Using it wrongly is worse than not using it |
| "Too much passive is bad style" | Not scored. Using the **wrong voice for the genre** is what costs |
| Using `I` in a Task 2 opinion essay | Fine, and a clear position is required. Vary the stance marker rather than avoiding the first person |
| Contractions | Correct in speech and informal letters; a slip only in essays and formal letters. **Flag by register, never globally** |
| Fillers in speech (`well`, `I mean`, `you know`) | Natural spoken English, not grammar errors |
| A single instance of any error | The scale is about pattern and control. Hunt your own repeat offenders, not errors in general |
| `less` vs `fewer` in speech | Extremely common; write `fewer`, and stop worrying about hearing `less` |

## 25. REGISTER: which of these belongs in Task 2, which in Speaking, which in neither

### 25.0 Why register is a grammar decision

Half of register is grammatical form — contractions, modal choice, phrasal-vs-Latinate verbs,
directness of a request, ellipsis. `02-what-moves-a-band.md` §2.3 item 3 makes the strongest possible
statement of the consequence: **a learner taught a single undifferentiated "English grammar" will
produce written grammar in Speaking Part 1 and spoken grammar in Task 2, and lose marks in both
directions.** Every structure in the Theory section must therefore carry a register tag, and this
section is the master table those tags are drawn from.

### 25.1 The master register table

`✓` = correct and expected · `~` = possible but not the best choice · `✗` = wrong for this context

| Form | Task 2 essay | Academic Task 1 | GT formal letter | GT informal letter | Speaking P1/P2 | Speaking P3 |
|---|---|---|---|---|---|---|
| Contractions (`don't`, `it's`) | ✗ | ✗ | ✗ | ✓ | ✓ | ✓ |
| `going to` for the future | ~ | ✗ | ~ | ✓ | ✓ | ✓ |
| `will` / `is likely to` / `is projected to` | ✓ | ✓ | ✓ | ~ | ✓ | ✓ |
| Agentless passive | ✓ | ✓ (required for processes) | ✓ | ~ | ~ | ✓ |
| `get`-passive (`got rejected`) | ✗ | ✗ | ✗ | ✓ | ✓ | ✓ |
| Second conditional | ✓ | ~ | ✓ | ✓ | ✓ | ✓ (essential) |
| Third conditional | ~ | ✗ | ✓ | ✓ | ✓ (P2 regret) | ✓ |
| `must` for obligation | ✓ (sparingly) | ~ | ✓ | ~ | ~ | ~ |
| `have got to` | ✗ | ✗ | ✗ | ✓ | ✓ | ✓ |
| `had better` | ✗ | ✗ | ~ | ✓ | ✓ | ✓ |
| `may` as a hedge | ✓ | ✓ | ✓ | ~ | ~ | ✓ |
| `tend to` / `in most cases` | ✓ (band-7 move) | ✓ | ✓ | ~ | ✓ | ✓ |
| Non-defining `, which …` | ✓ | ✓ | ✓ | ✓ | ~ | ✓ |
| `whereas` | ✓ | ✓ | ✓ | ~ | ~ | ✓ |
| `however` as a sentence adverb | ✓ | ✓ | ✓ | ~ | ~ | ✓ |
| `though` at the end of a clause | ✗ | ✗ | ✗ | ✓ | ✓ | ✓ |
| Phrasal verbs (`put off`, `find out`) | ~ (some are fine) | ~ | ~ | ✓ | ✓ | ✓ |
| Latinate equivalents (`postpone`, `ascertain`) | ✓ | ✓ | ✓ | ✗ (cold to a friend) | ~ | ~ |
| First person `I` | ✓ (opinion essays) | ✗ | ✓ | ✓ | ✓ | ✓ |
| Second person `you` (generic) | ✗ (use `people`, `one`, a passive) | ✗ | ~ | ✓ | ✓ | ✓ |
| Question tags | ✗ | ✗ | ✗ | ✓ | ✓ | ✓ |
| Ellipsis (`Been there twice.`) | ✗ | ✗ | ✗ | ~ | ✓ | ✓ |
| Tails (`It's expensive, that flat.`) | ✗ | ✗ | ✗ | ~ | ✓ | ~ |
| `sort of` / `kind of` as hedges | ✗ | ✗ | ✗ | ✓ | ✓ | ✓ |
| Clause chaining with `and … and …` | ✗ | ✗ | ✗ | ~ | ~ | ✗ |
| Nominalised subjects | ✓ | ✓ | ~ | ✗ | ✗ (stilted) | ~ |
| Cleft (`What matters is…`) | ✓ (once) | ~ | ~ | ~ | ✓ | ✓ |
| `gonna`, `wanna`, `kinda` (as spellings) | ✗ | ✗ | ✗ | ✗ | n/a — pronunciation only | n/a |
| Exclamation marks | ✗ | ✗ | ✗ | ✓ | n/a | n/a |
| Slang / text abbreviations | ✗ | ✗ | ✗ | ~ | ~ | ~ |

### 25.2 The three register rules a learner can remember

1. **Contractions flip.** Required in speech (their absence sounds memorised); wrong in an essay;
   correct in a friendly letter.
2. **Spoken English is a real grammar, not sloppy English.** Ellipsis, tails, fronting and `sort of`
   are *correct* spoken English — and would be errors in an essay. The reverse is also true:
   nominalised subjects and agentless passives sound stilted out loud.
3. **When you cannot decide, write neutral.** Neutral formal English is acceptable in every written
   context and only slightly stiff in speech. The reverse is not true — informal English in an essay
   is always a loss.

### 25.3 The forms that are too informal for ANY part of the test

`gonna` / `wanna` as written forms · text abbreviations (`u`, `pls`, `2moro`) · swearing · `ain't` ·
`innit` · double negatives used for emphasis (`I didn't do nothing`) · `they was` / `we was` ·
emoji · `LOL`-type interjections. These are all real English in some community; none of them belongs
in an exam answer, and a reference book should say **why** (they mark a specific informal community
register) rather than calling them "wrong", because a learner who hears them will otherwise distrust
the book.

## 26. Where usage genuinely varies — the honesty register

Rule 5 of this project's brief: where usage genuinely varies, say so explicitly rather than picking
one and hiding the other. Every item below is a real variation, not a mistake, and the theory
chapters must present them as such. The **Recommendation** column is what a learner preparing for an
IELTS-style test should actually do.

| Point | The variation | Recommendation |
|---|---|---|
| Present perfect with `just / already / yet` | BrE prefers the perfect; AmE freely uses the past simple | Use the perfect — accepted everywhere |
| `at the weekend` / `on the weekend` | BrE / AmE | Either |
| `in hospital` / `in the hospital`, `at university` / `at the university` | BrE drops the article for the institutional sense; AmE keeps it | Either; be consistent |
| `which` vs `that` in defining clauses | Free variation in BrE; some AmE style guides prescribe `that` | Not scored — the comma is |
| `If I was` / `If I were` | `were` is the standard formal subjunctive; `was` is very common in speech | Write `were` |
| `less` with countables | Widespread in speech; `fewer` is the careful written form | Write `fewer` |
| `none is` / `none are` | Both standard | Either |
| Collective nouns (`the team is/are`) | BrE allows both, with `are` when the members are meant; AmE strongly prefers singular | Either; be consistent within a text |
| `data is` / `data are` | `are` in strict scientific writing; `is` is now standard general usage | Either |
| `got` / `gotten` (past participle of `get`) | `gotten` is standard AmE; BrE uses `got` | Either |
| `shall` | BrE formal and in offers (`Shall I…?`); rare in AmE | `Shall I…?` is fine in speech; avoid elsewhere |
| `needn't` / `don't need to` | `needn't` is BrE and slightly formal | `don't need to` is universal |
| `have got` for possession | BrE informal (`I've got two`) vs `I have two` | Speech only |
| Two-syllable comparatives (`politer` / `more polite`) | Both standard | `more` is always safe |
| `due to` used adverbially | A prescriptive rule restricts it; usage ignores it | Not worth worrying about |
| Split infinitives, sentence-final prepositions, sentence-initial `And` | Prescriptive myths, not rules | Ignore |
| Singular `they` (`someone left their bag`) | Long-established and now fully standard in most contexts, including formal writing | Use it — it solves the gender problem cleanly |
| `Can I` for permission | Standard; the `may`-only rule is obsolete | Use `can`/`could`; `may` when very formal |
| `I'm loving it` (continuous of state verbs) | Real informal usage | Speech only; never in an essay |
| `whom` | Receding; obligatory only after a preposition | Use `who`, or restructure |
| `-ise` / `-ize` spellings | Both are British; `-ize` is standard American and also used by some British publishers | Either; be consistent |

## 28. Notes for the authors who build from this file

1. **Do not copy a practice point into a theory chapter.** A practice point teaches one decision in
   one direction with items. A theory chapter shows the **whole system at once** — every option side
   by side, in one table, on one screen. If a chapter cannot be read straight through by someone who
   has done no practice at all, it is the wrong document.
2. **The minimal pair is not optional.** It is the only evidence a learner has that a decision
   exists. A decision entry without a minimal pair will be read as "two ways to say the same thing".
3. **Every technical term gets defined the first time it appears in that chapter**, even though §0.3
   defines it globally. A reference book is entered in the middle, not read from page one.
4. **Keep the "deciding factor" to one line, and make it the thing the learner remembers.** If it
   takes three lines it is not a deciding factor, it is an explanation, and it belongs above.
5. **Name the false rule.** Nearly every decision in this file has a widely-taught wrong version
   (`present continuous = now`, `present perfect = recently`, `must is stronger than have to and
   that's all there is to it`, `whom is more correct`). The learner has probably met it. Interrupting
   it explicitly is more effective than quietly teaching the right version.
6. **Tag every entry with register.** The tags come from §25; do not invent new ones.
7. **Cross-link to the practice module.** Every decision here that has a practice point should link
   to it, and every contrast board in the practice module should link back here. The theory section
   is the map; the practice module is the route. A map with no route is a book; a route with no map
   is why learners plateau.
8. **Where usage varies, print both.** §26 is the list. A reference that hides variation loses the
   learner's trust the first time they hear the other form.
9. **Do not exceed what is true.** Several distinctions in this file are *tendencies* (`must` vs
   `have to`; `may` vs `might`; `will` vs `going to` for prediction). They are marked as such above
   and must stay marked. Presenting a tendency as a law is how learners end up "correcting" correct
   English.
