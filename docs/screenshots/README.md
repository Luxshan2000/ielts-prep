# Screenshots

The root [`README.md`](../../README.md) points here instead of embedding six images that do not
exist yet — a README full of broken image icons is a worse first impression than an honest
sentence. The captures land with the first tagged release.

Drop the real captures here under exactly these filenames, then replace the "Screenshots"
section of the root README with the embed table (one edit, and the paths already match):

| File | Screen |
|---|---|
| `dashboard.png` | Home / progress dashboard — band trend, streak, today's session |
| `speaking.png` | A live speaking session mid-turn |
| `writing.png` | The writing desk with an annotated evaluation open |
| `reading.png` | The reading test player with the question palette visible |
| `listening.png` | A listening test part with audio playing |
| `vocab.png` | The vocabulary review player or the deck list |

House rules so the set looks like one product rather than six screenshots:

- Capture **dark theme** (the app's default) at a 1440×900 window, 2× device pixel ratio.
- Use the shipped `core-en` content, never real personal practice history.
- Keep the sidebar visible in every shot so the screens read as one app.
- PNG, losslessly optimised, under ~400 KB each — this repository ships in a desktop installer.
