## Step-by-Step Learning Order
**Stage 1 — Foundations (A1–A2):** Brehe's Grammar Anatomy ch.1–5 → British Council A1–A2 (present/past simple, articles, prepositions) → englishpage.com tense drills + EnglishClub 12 tenses → keep Perfect English Grammar tense cheat-sheet PDF handy.

**Stage 2 — Building (B1–B2):** British Council B1–B2 (present perfect, future forms, modals, reported speech) → conditionals, passive, relative clauses on englishpage.com + Test-English → Cambridge Grammar Today as reference → Purdue OWL + College ESL Writers for writing accuracy.

**Stage 3 — Advanced (C1+, IELTS 8+):** British Council C1 (cleft sentences, inversion, emphasis) → Grammaring for nuance → EnglishGrammar.org C1–C2 exercises → keep a personal error log; apply advanced structures in timed IELTS writing.

Throughout: British Council Grammar app for daily spaced practice; Cambridge Grammar Today + Perfect English Grammar as go-to references.
